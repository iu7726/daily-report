### GitHub Copilot CLI 1.0.117 — MCP 승인 범위 수정, 샌드박스 사설 CA

MCP 서버의 도구를 세션이나 위치 단위로 승인하면, 서버 이름이 내장 권한 종류와 같을 때 셸 명령이나 메모리 저장 같은 Copilot 내장 요청까지 함께 승인되던 문제를 고쳤습니다. 이제 승인은 그 서버의 도구에만 적용됩니다.

샌드박스 명령이 TLS를 가로채는 사내 프록시를 거칠 때 쓸 사설 CA 인증서를 `sandbox.userPolicy.network.extraCaCertificates`로 지정할 수 있게 됐습니다.

| 변경 | 내용 |
|---|---|
| 사용자 지정 에이전트 | 도구를 명시적으로 켜야 쓸 수 있음(explicit tool exposure) |
| 자동 실행(autopilot) | 확장을 모두 거부하지 않고 확장마다 실행 전에 물음 |
| 설정 파일 | `config.json`을 읽지 못하면 파일을 건드리지 않고 플러그인 없이 시작 |
| 워크트리 | 샌드박스가 쓸 수 있는 연결 워크트리에서 커밋·브랜치·stash 다시 동작 |
| `--trust-folder` | 하위 폴더에서 실행할 때 저장소 루트의 훅을 실행하지 않음 |

> 사내 MCP 서버를 Copilot CLI에 붙여 쓰는 팀은 이 버전으로 올려야 합니다. 사내 프록시 때문에 샌드박스 안에서 `npm install`이 TLS 오류로 실패했다면 `extraCaCertificates`에 사내 CA를 넣으면 됩니다.

- 발표: 2026-11-27 · [Copilot CLI changelog](https://github.com/github/copilot-cli/blob/main/changelog.md)

### skills CLI 1.9.1 — `remove`·`sync` 수정

에이전트 스킬 설치 도구 `skills` 1.9.1이 나왔습니다. 에이전트 스킬 폴더가 심볼릭 링크일 때 `remove`가 원본 스킬까지 지우던 문제를 고쳤습니다. 전역 삭제가 프로젝트 스킬을 지우던 문제도 함께 고쳤습니다.

| 명령 | 바뀐 동작 |
|---|---|
| `sync --frozen-lockfile` | 원격 스킬을 잠금 파일에 적힌 커밋으로 받음 |
| `update` | 건너뛴 전역 스킬을 목록으로 보여 줌 |
| 잠금 파일 | 읽을 수 없는 전역 잠금 파일은 다시 쓰지 않음 |
| 다운로드 | 서버가 응답하지 않으면 시간 초과로 끝냄 |

> CI에서 `skills sync --frozen-lockfile`로 팀 스킬을 맞추고 있다면 이 버전부터 잠금 파일의 커밋이 그대로 지켜집니다. 다음에 스킬을 설치할 때 함께 올리면 됩니다.

- 발표: 2026-11-27 · [skills v1.9.1 릴리스](https://github.com/vercel-labs/skills/releases)
