## 3. 클라우드 (AWS)

### ① [P1] Babelfish for Aurora PostgreSQL — TDS 핸드셰이크에서 인증 없는 원격 코드 실행

AWS가 Babelfish의 TDS(SQL Server 호환 프로토콜) 처리 결함 2건을 공지했습니다. CVE-2026-119923은 연결 핸드셰이크(prelogin) 파서의 힙 버퍼 오버플로로, 인증 없이 TDS 포트에 조작된 패킷을 보내 DB 프로세스 권한으로 OS 명령을 실행할 수 있습니다(NVD 설명). CVE-2026-119924는 인증된 사용자가 RPC 요청으로 인접 메모리를 읽거나 서비스를 멈출 수 있는 결함입니다.

## 6. 데이터베이스

### ⑥ [P2] MariaDB — 파티션 변환으로 권한 없는 테이블 읽기·수정

MariaDB의 `ALTER TABLE ... CONVERT ... PARTITION`이 사용자가 정한 파티션 이름을 파일 이름 인코딩 없이 파일 경로에 씁니다. 인증된 DB 사용자가 특수 문자가 든 파티션 이름으로 권한 없는 다른 테이블 파일을 건드려 읽거나 바꿀 수 있습니다.

DB 계정을 여러 서비스·사용자가 나눠 쓰는 MariaDB 서버에서 의미가 큽니다. 공격자에게 `ALTER` 권한이 있는 계정이 있어야 합니다. MySQL은 이 공지 대상이 아닙니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| 10.11.1 이상, 각 계열 수정 버전 미만 | 10.11.19, 11.4.13, 11.8.9, 12.3.3, 13.0.2 | CVE-2026-102523 | 8.0 (NVD 기재) | 확인되지 않음 |

## 7. 공급망·CI/CD·인프라

### ⑦ [P2] OpenSSH 10.6p2 — musl·PAM 없는 Linux에서 비밀번호 인증 우회(sshole)

musl libc를 쓰고 PAM 없이 빌드한 sshd에서, 계정 설정에 따라 256 ~ 1024자 길이의 아무 비밀번호나 통과하는 문제입니다. OpenSSH는 원인이 sshd 밖에 있지만 sshd로 악용되므로 sshd에서 막았다며 11월 5일 10.6p2를 냈습니다. 대표적인 환경이 Alpine Linux입니다.

StepSecurity 분석에 따르면 `PasswordAuthentication yes`이고, 로그인이 허용된 계정 중 섀도 비밀번호가 `*`인 잠긴 계정과 실제 SHA-crypt 해시를 가진 계정이 함께 있어야 합니다. glibc 배포판(Ubuntu, Debian, Amazon Linux)과 비밀번호 인증을 끈 서버는 해당하지 않습니다.

> Alpine 이미지에 sshd를 넣어 쓰는 CI 러너·디버그 컨테이너·배스천이 있다면, 11월 5일 이전에 빌드한 이미지를 다시 빌드해야 합니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|

### ⑧ [P2] APT — HTTP 미러에서 검증 안 된 패키지 설치

Ubuntu·Debian의 APT가 HTTP 패키지 소스와 재시도 설정을 쓸 때, 호스트와 미러 사이 네트워크에 있는 공격자가 검증을 통과하지 못한 패키지를 설치시킬 수 있습니다. 그 패키지의 설치 스크립트는 root 권한으로 실행됩니다. Canonical과 Debian이 11월 4일 수정 패키지를 냈고, AWS도 공지를 냈습니다.

AWS 공지는 Ubuntu 22.04 LTS 이상과 Debian 12 이상이 기본 설정에서 영향을 받는다고 밝혔습니다. 네트워크 중간에 끼어들 수 있어야 하므로, 신뢰할 수 없는 네트워크에서 `apt-get`을 돌리는 빌드 환경이 가장 위험합니다.

> `node:*-bookworm`처럼 Debian·Ubuntu 기반 이미지에서 `apt-get install`을 돌리는 Dockerfile은 수정된 `apt`가 들어간 베이스 이미지로 다시 빌드해야 합니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| Ubuntu 22.04 LTS 이상, Debian 12 이상의 패치 이전 `apt` | Ubuntu 22.04 `2.4.15ubuntu0.1`, 24.04 `2.8.4ubuntu0.1`, 26.04 `3.2.1ubuntu0.1` / Debian은 DSA-6607-1 | CVE-2026-109518 | 확인 불가 | 확인되지 않음 |

- EC2 Ubuntu·Debian 인스턴스는 AWS가 대신 고치지 않습니다. `sudo apt-get update && sudo apt-get upgrade -o Acquire::Retries=0`으로 올립니다(AWS 안내).
- 컨테이너 이미지는 수정된 `apt`로 다시 빌드해 배포합니다.
- 원문: [AWS 보안 공지 2026-172-AWS](https://aws.amazon.com/security/security-bulletins/2026-172-aws/) (공개 2026-11-05 20:00 PST, 11-06 13:00 KST · 갱신 11-06 13:30 PST)
