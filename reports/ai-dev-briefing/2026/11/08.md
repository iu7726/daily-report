### 1. Vercel AI SDK `ai` 7.0.165 — 텔레메트리에서 요청 URL 인증 정보 제거

11월 8일 04:27 KST에 `ai` 7.0.165가 나왔습니다. 텍스트 생성 결과가 텔레메트리와 트레이싱에 기록되기 전에 공급자 요청 URL을 정리합니다. 릴리스 노트는 이 변경이 엔드포인트 인증 정보 노출을 막는다고 밝혔습니다.

함께 `recordOutputs: false`일 때 음성 변환(transcription)의 단어별 시각 정보도 텔레메트리에서 빠집니다. 6.x(6.0.325)와 5.x(5.0.286)에는 `recordOutputs: false`일 때 공급자 메타데이터를 숨기는 수정이 들어갔고, 5.0.286은 SDK 도구가 비어 있어도 `toolChoice: 'none'`을 유지합니다.

> `experimental_telemetry`로 Langfuse·Datadog 같은 수집기에 트레이스를 보내는 NestJS 서비스라면, 쿼리 문자열이나 경로에 키가 들어가는 공급자·게이트웨이 URL이 이미 기록됐는지 수집기에서 확인하고 `ai`를 올리세요. 기록이 남아 있다면 키를 교체해야 합니다.

- 발표: 2026-11-07(미국 날짜) · [vercel/ai 릴리스](https://github.com/vercel/ai/releases)

### 2. LangChain.js — `@langchain/openai` 1.8.2 바이너리 전송 수정, `langchain` 1.6.3

11월 7일 13:26 KST에 LangChain.js 패키지 여러 개가 함께 나왔습니다. `@langchain/openai` 1.8.2는 이미지·오디오·파일 콘텐츠 블록의 `Uint8Array` 데이터를 Chat Completions API로 보낼 때 base64로 인코딩합니다. 전에는 쉼표로 구분한 10진수 바이트 문자열로 나갔습니다.

`langchain` 1.6.3의 `modelRetryMiddleware`는 `retryOn`에 넣은 오류의 하위 클래스도 재시도해 `toolRetryMiddleware`와 동작을 맞췄고, 미들웨어를 거친 모델 오류가 원래 정보를 유지하도록 고쳤습니다. `@langchain/anthropic` 1.6.1은 메시지를 다시 보낼 때 스트리밍된 `server_tool_use` 입력을 보존합니다.

> 업로드 파일을 `Buffer`·`Uint8Array` 그대로 LangChain 메시지에 넣던 백엔드는 1.8.2로 올린 뒤 결과를 다시 확인하세요. `retryOn`에 상위 오류 클래스를 넣어 둔 경우 업그레이드 후 재시도 횟수와 비용이 늘 수 있습니다.

- 발표: 2026-11-07(npm 게시 13:26 KST) · [langchainjs 릴리스](https://github.com/langchain-ai/langchainjs/releases)

### 3. GitHub Copilot 코드 리뷰 — REST API 설정 관리, 리뷰 화면 정리

GitHub Changelog 11월 6일 글에서 Copilot 코드 리뷰 설정을 엔터프라이즈·조직·저장소 단위로 REST API에서 관리할 수 있게 됐습니다. 응답에는 리뷰 강도(effort)와 함께 Copilot이 코멘트 근거로 밝힌 스킬, MCP 서버, 사용자 지정 지침이 표시됩니다. 저장소 설정 엔드포인트만 GitHub App과 세분화된 PAT를 지원하고, 엔터프라이즈·조직·러너 엔드포인트는 지원하지 않습니다.

리뷰 개요는 결과를 위로 모으고 검토하지 않은 파일을 한 절로 묶었습니다. "자동 Copilot 코드 리뷰 요청" 규칙에 예외 대상 목록이 생겼고, Balanced 강도 리뷰는 리뷰 모델 3개의 결과를 네 번째 모델이 합칩니다. 실패하거나 시간이 초과된 리뷰는 한 번 자동 재시도합니다.

> 저장소마다 Copilot 리뷰에 MCP 도구와 사용자 지정 지침을 쓸지 API로 일괄 설정할 수 있습니다. 봇이 만든 의존성 PR까지 자동 리뷰가 돌아 비용이 늘었다면 예외 대상 목록에 Dependabot 등을 넣으세요.

- 발표: 2026-11-06 · [GitHub Changelog](https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates)

### `improve-codebase-architecture` (mattpocock/skills)

코드베이스에서 "얕은 모듈"(구현에 비해 인터페이스가 복잡한 모듈)을 찾아 깊은 모듈로 합치는 리팩터링 후보를 제안하는 스킬입니다. 범위를 지정하지 않으면 `git log --oneline`으로 최근 자주 바뀐 곳부터 보고, `GLOSSARY.md`와 `docs/adr/`의 결정을 먼저 읽어 이미 정한 사항은 다시 따지지 않습니다.

후보는 OS 임시 폴더에 HTML 보고서(Tailwind·Mermaid CDN 사용)로 만들어 열어 주고, 하나를 고르면 `grilling` 스킬로 제약과 테스트 경계를 묻는 대화로 이어갑니다. 진행 중 `GLOSSARY.md`를 갱신하거나 ADR 작성을 제안합니다. SKILL.md에 `disable-model-invocation: true`가 있어 사용자가 직접 호출해야 동작합니다.
