### 3. Anthropic TypeScript SDK 1.13.0, Enterprise Frontier Safeguards 베타

### 4. OpenAI Node SDK 7.63.0 — 에이전트 세션 지출 한도

11월 24일 04:13 KST(npm 게시)에 `openai` 7.63.0이 나왔습니다. 베타 에이전트 세션 생성·수정 요청에 `spend_control` 필드가 생겼고, USD 센트 단위로 최선 노력(best-effort) 한도를 겁니다. 한도에 닿으면 세션 상태가 `budget_reached`가 되고, 턴 오류 `session_budget_exceeded`와 이벤트 `agent.session.budget_reached`가 옵니다.

수정 요청에서 `spend_control`을 빼면 기존 한도가 유지되고, 한도를 null로 보내면 해제됩니다. 이 기능은 SDK 변경 이력에만 있고, OpenAI API 변경 이력에는 아직 항목이 없습니다(확인 시점 기준).

> Agents API로 장시간 세션을 돌리는 백엔드라면 세션마다 한도를 걸고, 새 상태와 이벤트를 처리하는 분기를 이벤트 핸들러에 추가하세요. 한도가 정확히 지켜지지 않는 최선 노력 방식이라 조직 단위 지출 한도도 함께 두는 편이 안전합니다.

- 발표: 2026-11-23 · [openai-node CHANGELOG](https://github.com/openai/openai-node/blob/master/CHANGELOG.md) · [PR #3187](https://github.com/openai/openai-node/pull/3187)

> 에이전트 루프가 단계 한도에 걸려 끝났는지, 모델이 스스로 멈췄는지 로그로 구분하고 싶었다면 `stoppedBy`를 기록하세요. 프로바이더 옵션에 키나 내부 값을 넣어 쓰고 있다면 이 버전으로 올려 트레이스에서 빠지는지 확인하세요.

### 6. OpenAI·Cisco Shirudo — 패치 전까지 취약점을 막는 eBPF 런타임

11월 23일 OpenAI와 Cisco가 오픈소스 런타임 Shirudo를 공개했습니다. 정식 패치가 나오기 전까지 실행 중인 Linux 시스템에 eBPF로 "실드"를 걸어, 익스플로잇이 기대는 특정 동작만 막습니다. 재시작이 필요 없고, 실드는 서명 검증 후 적재됩니다.

공개 시험에서는 Codex가 만든 실드가 실행 중인 Elasticsearch 프로세스의 Java Base64 디코더에 입력 검사를 붙여 악성 입력을 거부했습니다. 라이선스는 BSD 2-Clause(BPF 프로그램은 BSD·GPL 이중)입니다.

> Node.js 앱 코드를 바꿀 일은 없습니다. 다만 Linux 서버를 직접 운영하는 팀이라면 취약점 공개부터 패치 배포까지의 공백을 메우는 선택지로 알아 두세요. 아직 초기 프로젝트라 운영 적용보다는 VM 빠른 시작으로 먼저 시험해 보는 단계입니다.

- 발표: 2026-11-23 · [OpenAI 글](https://openai.com/index/introducing-shirudo/)

### `claude-api` (anthropics/skills)

Claude API와 Anthropic SDK로 앱을 만들거나 고칠 때 모델 ID, 파라미터, 스트리밍, 도구 사용, 캐싱 규칙을 참조하게 하는 스킬입니다. 프로젝트 언어를 감지해 TypeScript면 `@anthropic-ai/sdk` 문서를 읽고, 문서에 없는 SDK 사용법은 추측하지 말고 공식 저장소에서 확인하도록 지시합니다.

하위 명령으로 `migrate`(새 모델로 코드 이전), `prompt-audit`(오래된 프롬프트 점검), `cost-optimize`, `build-eval`, `hillclimb` 등이 있습니다. Opus 5.5 이전 가이드도 `/claude-api migrate this project to claude-opus-5-5`로 옮기라고 안내합니다.

skills.sh 소개 문구는 기본 모델을 Opus 4.6으로 적고 있지만, 저장소의 현재 SKILL.md는 `claude-opus-5-5`와 adaptive thinking을 기본으로 씁니다. 설치하면 저장소 최신본이 들어오므로 SKILL.md 기준으로 보면 됩니다.
