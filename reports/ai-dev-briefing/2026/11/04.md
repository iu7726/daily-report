### 1. Claude Code 2.1.317 — `claude -p` 종료 코드, Agent SDK 훅 차단 옵션

11월 3일 08:57 KST에 Claude Code 2.1.317이 npm에 올라왔습니다. 디스크가 가득 차거나 할당량 초과로 대화 기록·`~/.claude.json` 쓰기가 실패하면, `claude -p`가 예전에는 0으로 끝났지만 이제 오류를 출력하고 종료 코드 1을 반환합니다(text·json 출력).

같은 버전에서 Agent SDK 훅 콜백에 `onFailure: "block"`이 추가됐습니다. 콜백 자체가 실패하면 그 동작을 실행하지 않고 막습니다. Read 도구가 바뀌지 않은 파일에 대해 돌려주던 "file unchanged" 안내문도 없어져, 같은 파일을 다시 읽으면 내용을 그대로 돌려줍니다.

> CI에서 `claude -p` 결과로 리뷰·코드 생성을 돌리는 파이프라인은 실패 처리 분기가 실제로 타는지 확인하고, Agent SDK로 만든 Node.js 서비스에서 보안 검사 훅을 쓴다면 `onFailure: "block"`을 걸어 검사 오류 시 그냥 통과되지 않게 하는 편이 안전합니다.

그 밖에 셸·웹 도구가 계정 이메일 주소를 네트워크로 보내기 전에 묻는 확인, OTel 지표의 `anthropic.plan` 등 속성 추가, TLS 검사 프록시 뒤에서 루트 인증서 갱신 후 "unable to get local issuer certificate" 오류 수정이 들어갔습니다. `@anthropic-ai/claude-agent-sdk` 0.3.317도 같은 시각에 배포됐습니다.

### 2. openai Node SDK 7.48.0·7.49.0 — Live Responses 위임 타입 확장, 워크로드 아이덴티티

`openai` 7.48.0(11/4 03:31 KST)은 Live Responses 위임(delegation)에 쓰는 도구 정의와 도구 선택(choice) 타입을 늘렸습니다. 릴리스 노트에 "전수 `switch`를 쓰는 코드는 새 변형을 처리해야 할 수 있다"고 명시돼 있습니다. 기존 function·MCP 선택 이름과 필수 필드는 그대로 동작합니다.

이어서 나온 7.49.0(11/4 05:42 KST)은 워크로드 아이덴티티 공급자와 연동(federation) 규칙 API를 추가했습니다. 7.48.0에는 Responses WebSocket 출력 정보 보존 기능도 들어갔습니다.

> `never` 검사로 타입을 전수 처리하는 NestJS 서비스는 `^7` 범위 자동 업그레이드만으로 빌드가 깨질 수 있으니, lockfile 갱신 PR에서 `tsc --noEmit`을 먼저 돌려 보세요.

- 발표: 2026-11-03 · [openai-node CHANGELOG](https://github.com/openai/openai-node/blob/master/CHANGELOG.md) · [PR #3101](https://github.com/openai/openai-node/pull/3101)

### 3. Claude API — 일부 모델 생성 텍스트에 워터마크 적용

11월 3일 Claude Platform 릴리스 노트에 따르면 Claude Mythos 5, Claude Opus 4.7, Claude Sonnet 4.6이 만든 텍스트에 Anthropic 텍스트 워터마크가 붙습니다. 적용 플랫폼은 지원 문서에 따로 정리돼 있습니다.

워터마크는 토큰이나 숨은 문자를 추가하지 않고 의미·품질도 바꾸지 않아 요청·응답 처리 코드를 고칠 필요가 없습니다. 다만 Claude Sonnet 4.6에서 `temperature`, `top_p`, `top_k`를 기본값이 아닌 값으로 보내면 워터마크가 빠질 수 있습니다.

> 응답 문자열을 비교·해시하는 테스트는 영향이 없지만, 규제 대응으로 워터마크가 필요한 서비스라면 Sonnet 4.6 호출에서 프레임워크가 몰래 넣는 샘플링 파라미터까지 빼야 합니다.

- 발표: 2026-11-03 · [릴리스 노트](https://platform.claude.com/docs/en/release-notes/overview) · [Text watermark 문서](https://platform.claude.com/docs/en/build-with-claude/text-watermark)

### 4. Dependabot — Agent Package Manager(APM) 버전 업데이트 지원

Dependabot이 `apm.yml`에 선언된 git 의존성(에이전트 스킬·프롬프트·지침)을 올리는 PR을 만들고, `apm.lock.yaml`이 있으면 다시 생성합니다. `.github/dependabot.yml`에 `package-ecosystem: "apm"` 항목을 추가하면 됩니다. 버전 업데이트만 지원하고 보안 업데이트는 대상이 아닙니다.

> 팀 저장소에 스킬을 APM으로 고정해 두고 있다면, 스킬 갱신도 일반 npm 의존성처럼 PR 리뷰를 거치게 할 수 있습니다. 스킬은 에이전트에 실행 지시를 주므로 자동 병합은 걸지 않는 편이 낫습니다.

- 발표: 2026-11-03 · [GitHub Changelog](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager)

### `triage` (mattpocock/skills)

이슈와 외부 PR을 `needs-triage` → `needs-info` → `ready-for-agent`/`ready-for-human`/`wontfix` 상태로 옮기며 분류하는 스킬입니다. 버그는 재현을 시도하고, 정보가 부족한 이슈는 질문을 이어 가며, 에이전트에게 넘길 작업 지시서 템플릿을 만듭니다. 올리는 모든 코멘트 앞에 "AI가 생성했다"는 안내 문구를 붙이도록 정해져 있습니다.
