### 2. Claude Code 2.1.321 — MCP OAuth 비밀값 유출, 권한 확인 우회 수정

11월 10일 04:02 KST(npm 게시)에 2.1.321이 나왔고, Fable 5.2가 기본 Fable 모델이 됐습니다. 보안 관련 수정이 여러 건 들어 있습니다.

- MCP 서버가 리다이렉트하면 OAuth 요청이 refresh token 같은 비밀값을 다른 호스트로 보내던 문제
- 읽기 전용 Bash 명령이 권한 확인 없이 샌드박스 밖에서 실행되던 경우

- `cp`·`mv`로 디렉터리에 복사·이동한 파일에 deny 규칙과 보호 파일 확인이 적용되지 않던 문제

그 밖에 `claude remote-control --settings <file>` 옵션이 추가됐고, fast mode가 속도 제한·과부하일 때 먼저 같은 모델의 표준 속도로 재시도합니다. `claude -p`가 백그라운드 명령 제한 시간을 30분으로 잘못 안내하던 문제(실제 10분)도 고쳤습니다. `@anthropic-ai/claude-agent-sdk`도 0.3.321로 함께 나왔습니다.

> 원격 MCP 서버를 OAuth로 붙여 쓰거나 CI에서 deny 규칙으로 `.env`·비밀 파일을 막아 두었다면 2.1.321로 올리세요. 신뢰하지 않는 MCP 서버에 로그인했던 적이 있다면 그 서비스의 토큰을 다시 발급하는 편이 안전합니다.

### `tdd` (mattpocock/skills)

에이전트가 테스트 주도 개발(red → green)로 기능을 만들게 하는 지침 스킬입니다. 내부 구현이 아닌 공개 인터페이스로 동작을 검증하는 테스트를 쓰게 하고, 테스트를 한꺼번에 먼저 쓰지 않고 테스트 하나와 구현 하나씩 번갈아 진행합니다.

테스트를 쓰기 전에 어느 경계(seam)를 테스트할지 사용자와 먼저 합의합니다. 내부 협력 객체를 목(mock)으로 막거나 DB를 직접 조회해 검증하는 테스트, 코드와 같은 계산으로 기댓값을 만드는 테스트를 피해야 할 패턴으로 꼽습니다. 리팩터링은 루프 밖 리뷰 단계로 미루고, `GLOSSARY.md`와 ADR이 있으면 읽습니다.
