## 5. 런타임·프레임워크

### ③ [P2] picomatch — 수정판 없는 ReDoS, `npm audit`에 High로 표시

glob 매처 `picomatch`가 `+(*)`, `+(*a)` 같은 한 갈래짜리 반복 extglob 패턴을 거르지 못합니다. 이런 패턴으로 짧은 문자열을 맞춰 보면 정규식이 지수 시간 동안 되돌아가며 Node.js 이벤트 루프를 막습니다. 10월 19일 NVD에 공개된 CVE가 이번에 GitHub DB에 검토 권고로 올라왔습니다.

공격자가 **glob 패턴 자체**를 넘길 수 있는 코드만 해당합니다. 빌드 도구, 파일 감시(chokidar), 고정된 패턴으로 파일을 찾는 일반적인 쓰임은 해당하지 않습니다. 다만 거의 모든 프로젝트에 간접 의존성으로 들어 있어, 오늘부터 `npm audit`와 Dependabot이 고칠 수 없는 High 경고를 띄웁니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| 4.0.7 이하(전 버전) | 없음(수정 PR #194 검토 중) | CVE-2026-112366, GHSA-fc5q-39xc-vjpf | 7.5 (CVSS 3.1) | 미등재 · 확인 불가 |

> 경고를 없애려고 의존성을 억지로 바꿀 필요는 없습니다. 검색 필터, 라우팅 규칙, 파일 선택 API처럼 사용자 입력을 glob 패턴으로 쓰는 곳이 있는지만 확인합니다.

- 사용자 입력을 패턴으로 넘기는 코드가 있다면 `+(`, `*(`, `@(` 같은 extglob 문법을 막거나 `noextglob: true` 옵션을 줍니다.
- 그런 코드가 없다면 수정판이 나올 때까지 경고를 기록해 두고 넘어갑니다.
- 원문: [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) (NVD 공개 2026-10-20 01:17 KST · GitHub DB 등록 2026-11-18 00:56 KST) · [picomatch PR #194](https://github.com/micromatch/picomatch/pull/194)
