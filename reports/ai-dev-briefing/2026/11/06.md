## 주요 소식

### 1. Claude Console IP 허용 목록(베타), Admin API 구성원 일괄 로그아웃

11월 5일 Claude Platform 릴리스 노트에 조직 IP 허용 목록 베타가 올라왔습니다. IPv4·IPv6 주소나 CIDR 범위를 조직당 1,000개까지 등록하고, 목록 밖에서 온 요청은 거부합니다. API 키가 새도 쓸 수 있는 위치를 좁히려는 기능입니다.

적용 대상은 Claude Console 화면, Messages·Message Batches·Token Counting·Models·Files·Skills API, Managed Agents API, Admin·Compliance API입니다. 거부된 Messages 요청은 403 `permission_error`와 `Your IP address isn't in this organization's allowed range.` 메시지를 받습니다. Amazon Bedrock, Google Cloud, Microsoft Foundry 경유 호출에는 적용되지 않고, 설정 변경은 반영까지 최대 15분이 걸립니다.

같은 날 Claude Enterprise 구성원을 모든 기기에서 로그아웃시키는 Admin API `POST /v1/organizations/users/{user_id}/sign_out`도 베타로 나왔습니다. `admin-user-sign-out-2026-10-08` 베타 헤더가 필요합니다.

> 허용 목록을 켜기 전에 운영 서버, CI 러너, 하루·주 단위로만 도는 배치 작업의 나가는 공인 IP를 빠짐없이 등록해야 합니다. NestJS 예외 필터에서 403 `permission_error`를 재시도 대상으로 두고 있다면 빼고, 별도 알림으로 잡는 편이 낫습니다.

- 발표: 2026-11-05 · [릴리스 노트](https://platform.claude.com/docs/en/release-notes/overview) · [IP allowlisting 문서](https://platform.claude.com/docs/en/manage-claude/ip-allowlist)

### 2. Anthropic TypeScript SDK 1.6.0 — 오류 `name`을 클래스 이름으로 설정

`@anthropic-ai/sdk` 1.6.0이 11월 6일 04:05 KST에 npm에 올라왔습니다. 1.5.0에서 추가된 오류 클래스마다 `name`이 클래스 이름으로 설정되고, `WorkloadIdentityError`의 이름도 고쳐졌습니다.

기능으로는 램프 한도(ramp limit) 오류 코드, 외부 키(External Key) 검증 실패 오류 코드, 위 1번의 구성원 일괄 로그아웃 API 지원이 추가됐습니다. 문서에는 API 오류의 타입·메시지·코드·상세 설명이 보강됐습니다.

> 로그 수집기나 Sentry에서 `err.name` 값으로 오류를 묶고 있었다면 업그레이드 후 그룹이 새로 생기고 대시보드 필터가 맞지 않을 수 있습니다. 분기는 `instanceof`나 `errorCode`로 하고, `name`은 표시용으로만 쓰는 편이 안전합니다.

- 발표: 2026-11-05(체인지로그 날짜) · [CHANGELOG](https://github.com/anthropics/anthropic-sdk-typescript/blob/main/CHANGELOG.md) · [npm](https://www.npmjs.com/package/@anthropic-ai/sdk)

### 3. openai Node SDK 7.51.0·7.52.0 — 데이터 상주 지역 추가, Responses 옵션 확장

`openai` 7.51.0(11/5 10:05 KST)은 클라이언트 옵션 `dataResidency`에 호주(`au`)·인도(`in`)·일본(`jp`)을 추가했습니다. 같은 버전에 GPT-6 Rosalind 모델 목록 등록, 이미지 복잡도와 GIF·SVG 출력 옵션, 에이전트 세션 턴 실패 코드 `max_output_tokens`, Responses 이미지 컨텍스트 압축 옵션, Realtime 입력 음성 잡음 제거 강도 설정이 들어갔습니다.

7.52.0(11/6 03:14 KST)은 Responses 요청의 모델 선택지를 늘렸습니다. PR 리뷰에 따르면 모델 유니온에 값을 더한 변경이라 기존 모델 문자열은 그대로 동작합니다. GPT-6 Rosalind 자체는 API 변경 이력 10월 30일 항목으로 이미 공개된 모델입니다.

> 일본·호주·인도 리전 고객 데이터를 다루는 서비스는 `dataResidency` 옵션으로 지역을 고정할 수 있게 됐습니다. 에이전트 턴 실패 코드를 전수 `switch`로 처리하는 코드는 `max_output_tokens` 분기가 빠지지 않았는지 `tsc --noEmit`으로 확인하세요.

- 발표: 2026-11-05(체인지로그 날짜) · [openai-node CHANGELOG](https://github.com/openai/openai-node/blob/master/CHANGELOG.md) · [PR #3112](https://github.com/openai/openai-node/pull/3112) · [PR #3116](https://github.com/openai/openai-node/pull/3116)

### 4. OpenAI GPT-6-Cyber — 취약점 조사·재현용 모델 공개

OpenAI API 변경 이력 11월 5일 항목에서 `gpt-6-cyber`가 공개됐습니다. 승인된 테스트 환경에서 취약점을 조사·재현하고 수정이 맞는지 검증하는 용도의 모델입니다. 모델 문서에 따르면 조직이 Daybreak Red 접근 승인을 받아야 쓸 수 있습니다.

### 5. Gemini Omni 1.2 Flash 정식 출시, Gemini API 오피스 파일 입력 확대

Google이 11월 5일 영상 생성 모델 `gemini-omni-1.2-flash`를 Gemini API와 Vertex AI에 정식 출시했습니다. 클립 길이가 최대 15초로 늘고(3 ~ 15초, 1초 단위), 대화형 편집과 참조 이미지 일관성이 개선됐으며, 720p 영상 출력 가격은 초당 $0.07로 30% 내렸습니다. 12월 3일부터 `gemini-omni-1.1-flash` 요청은 1.2 Flash로 넘어가 1.2 Flash 요금으로 청구됩니다.

같은 날 Gemini API 변경 이력에는 PPT·ODP·ODS 파일 입력, DOC 파일의 페이지 이미지 처리, 함수 응답(function response)에서 오피스 문서·오디오·영상을 모델에 돌려주는 기능이 추가됐습니다.

> `gemini-omni-1.1-flash`를 고정해 쓰는 서비스는 12월 3일 이후 결과물과 비용이 바뀌니 그 전에 1.2 Flash로 시험해 두세요. 도구 호출 결과로 파일을 돌려주는 백엔드는 이제 문서를 텍스트로 변환하지 않고 그대로 넘길 수 있습니다.

- 발표: 2026-11-05 · [Google 블로그](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/) · [Gemini API 변경 이력](https://aistudio.google.com/docs/changelog)
