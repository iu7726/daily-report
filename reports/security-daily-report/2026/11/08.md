## 1. 긴급 조치 요약

즉시 조치가 필요한 신규 이슈 없음

이전 보고에서 다뤘고 아직 조치 기간인 P1입니다.

- **Babelfish for Aurora PostgreSQL(11월 7일 보고 ①, CVE-2026-119923)**: Babelfish를 켠 클러스터는 수정 버전(예: 16.13.3, 17.9.3, 18.3.4 이상)으로 올리고, 그 전까지 TDS 포트(기본 1433)를 보안 그룹으로 막습니다. 11월 7일 이후 AWS 공지에 바뀐 내용은 없습니다.
- **Node.js Brotli(CVE-2026-111497)**: KEV 조치 기한이 11월 10일(화)입니다. v22.23.4 / v24.22.1 / v26.12.1 미만이면 올립니다.
- **self-managed GitLab(11월 3일 보고, CVE-2026-97229)**: 10월 29일 패치(19.5.3 / 19.4.5 / 19.3.7 등) 이후 새 패치는 없습니다.
- **Cursor의 Claude Code 확장 변조판(11월 3일 보고)**: 10월 29일 Cursor에서 `anthropic.claude-code` 2.1.312·2.1.313을 받았다면 `~/.ssh/authorized_keys`에 `svc-telemetry` 키가 있는지 확인합니다.
- **Linux 커널 TCP(CVE-2026-98432)**: EC2 커널 교체와 RDS·Aurora 대기 중인 OS 패치를 적용합니다.

이번 주 안에 할 일로 11월 7일 보고의 OpenSSH sshole(Alpine), APT, MariaDB, `@graphql-tools/utils` 업그레이드가 남아 있습니다.

## 4. AI·개발 도구

참고

- ① Vercel AI SDK `ai` 7.0.165 — 텍스트 생성 결과가 텔레메트리 연동과 트레이싱 구독자에게 넘어가기 전에 공급자 요청 URL을 정리하도록 고쳤습니다. 릴리스 노트는 엔드포인트 자격 증명이 노출되는 것을 막으려는 수정이라고 적었습니다. URL에 키를 넣는 공급자 설정을 쓰면서 OpenTelemetry 같은 텔레메트리를 켜 두었다면 올리는 편이 좋습니다. 보안 권고나 CVE는 없고, 같은 날 나온 6.0.325·5.0.286에 같은 수정이 들어갔는지는 확인 불가입니다. 게시 2026-11-08 04:27 KST · [ai@7.0.165 릴리스](https://github.com/vercel/ai/releases/tag/ai%407.0.165)

Claude Code는 2.1.319(11월 7일 보고) 이후 새 버전이 없고, Codex는 0.169.0-alpha 사전 릴리스만 나왔습니다. Codex 보안 권고는 2025년 9월 이후 없고, Gemini CLI 보안 권고는 비어 있습니다. Cursor 변경 이력의 최신 글은 11월 6일 음성 대화이고, VS Code는 11월 6일 1.145.2 이후 새 릴리스가 없습니다. GitHub Changelog의 11월 6일 ~ 7일 글은 Copilot 기능 소식뿐입니다.

MCP TypeScript SDK 권고는 10월 15일이 마지막입니다. `langchain` 1.6.3과 LangChain 통합 패키지(11월 7일) 릴리스 노트에 보안 수정은 없고, `openai`(7.53.0), `@anthropic-ai/sdk`(1.6.0), `@langchain/core`(1.3.5)는 새 버전이 없습니다.

이상 없음으로 확인한 대상: Claude Code, OpenAI Codex, Cursor, GitHub Copilot, Gemini CLI, VS Code, MCP 공식 SDK, LangChain.js, OpenAI·Anthropic SDK, Vercel AI SDK(① 외 신규 없음)

확인 실패: VS Code Marketplace·Open VSX (공식 공지 페이지를 직접 확인하지 못함. 웹 검색과 보안 업체 블로그 목록에서는 조사 기간의 신규 사건이 보이지 않음)
