### 2. NestJS 12.5.0·11.2.10 — 새 기본 제한과 시작 단계 실패

보안 수정과 함께 여러 기본값이 바뀌었습니다. 호환성을 깨는 변경(breaking change)으로 표시되지는 않았지만, 지금까지 통과하던 요청이 거절되거나 앱이 뜨지 않을 수 있습니다. npm 게시는 12.5.0이 11월 12일 22:13 KST, 11.2.10이 11월 13일 03:52 KST입니다.

| 항목 | 바뀐 점 |
|---|---|
| `WsAdapter` `maxPayload` | 기본 1MB(이전 100MB). 넘으면 코드 1009로 연결 종료, `0`이면 제한 없음 |
| multipart (Express·Node) | 기본 최대 1000개 부분. `limits.parts`로 늘림 |
| TCP 마이크로서비스 | `maxBufferSize` 기본 16Mi 문자(이전 128Mi), 빈 `host`는 localhost에서만 대기 |
| 새 제한 옵션 | `IoAdapter` `maxWaitingMessages` 10,000, TCP `maxConcurrentMessages` 1000, gRPC `maxPendingResponses` 1000, RabbitMQ `maxMessageSize` 16MiB 등 |
| 상태 코드 | 400이 없는 `SyntaxError`·`URIError`는 500으로 응답, 경로 파라미터가 비면 404(`platform-node`) |
| 시작 단계 실패 | 잘못된 `forRoutes()`·`exclude()` 항목, 실행할 수 없는 가드·인터셉터·파이프 |

TCP 마이크로서비스를 `host` 없이 띄우고 다른 컨테이너에서 붙고 있었다면 올린 뒤 연결이 끊깁니다. 릴리스 노트는 `'0.0.0.0'`이나 `'::'`을 명시하라고 안내합니다.

> 올린 뒤 스테이징에서 앱 시작, 큰 파일·다중 파일 업로드, WebSocket 대용량 메시지, 마이크로서비스 연결을 한 번씩 확인하세요. `app.use()`에 넘긴 미들웨어가 던진 오류에 400을 기대하는 테스트가 있다면 500으로 바뀝니다.

- 발표: 2026-11-12 · [v12.5.0 릴리스](https://github.com/nestjs/nest/releases/tag/v12.5.0) · [v11.2.10 릴리스](https://github.com/nestjs/nest/releases/tag/v11.2.10)

### 3. Gemini 4 Hydrogen 정식 출시, `@google/genai` 3.3.0

Google이 11월 12일(미국 날짜) Gemini 4 Hydrogen을 Gemini API에서 정식 출시(GA)했습니다. Google은 Carbon·Argon을 최상위 모델로, Hydrogen을 에이전트 작업용 "일상 모델"로 소개합니다. 무료 등급에서도 쓸 수 있습니다.

| 항목 | 값 |
|---|---|
| 모델 ID | `gemini-4-hydrogen` |
| 컨텍스트 | 1,048,576 토큰(입력·생각·출력 합계), 동기 응답 최대 65,536 토큰 |
| 가격 (입력/출력, 100만 토큰) | $1.50 / $7.50, 암묵적 캐시 입력 $0.075 |
| 생각 수준 | `low` / `medium` / `high`(기본) / `xhigh`. `minimal`은 오류 |
| 미지원 | 명시적 캐싱(`cachedContents`, `caches.create`), `temperature`·`top_p`·`top_k`(무시됨) |

Gemini 3.8 Flash에서 옮길 때 바뀌는 점이 많습니다. 명시적 캐시를 쓰던 코드는 `cached_content`를 빼야 하고, 기본 생각 수준이 `medium`에서 `high`로 올라 지연 시간과 생각 토큰이 늘어납니다. `max_output_tokens`를 8,192처럼 낮게 고정해 두었다면 잘릴 수 있으니 65,536으로 올리라고 문서가 안내합니다.

같은 날 06:19 KST(npm 게시)에 나온 `@google/genai` 3.3.0은 Interactions API 모델 열거형에 `gemini-4-hydrogen`을 넣고 `ThinkingLevel`에 `XHIGH`를 정식으로 추가했습니다.

> NestJS 서비스에서 3.8 Flash를 쓰고 있다면 `@google/genai`를 3.3.0으로 올리고, 캐시 생성 코드와 `minimal` 생각 수준, 낮은 `max_output_tokens`를 먼저 찾아 고치세요. 기본값 `high`가 느리면 `medium`을 명시해 평가해 보세요.

- 발표: 2026-11-12 · [Google 발표](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/) · [Gemini API 변경 이력](https://aistudio.google.com/docs/changelog) · [What's new in Gemini 4 Hydrogen](https://aistudio.google.com/docs/whats-new-gemini-4-hydrogen) · [`@google/genai` v3.3.0](https://github.com/googleapis/js-genai/releases/tag/v3.3.0)

### 4. Claude Code 2.1.323 — 실험 기능 Code Mode, 플러그인 버전 범위

11월 13일 05:29 KST(npm 게시)에 Claude Code 2.1.323이 나왔습니다. Claude가 도구를 하나씩 부르는 대신 JavaScript를 써서 도구를 호출하는 실험 기능 Code Mode가 추가됐고, 직접 켜야 동작합니다. 조직 단위로 끌 수도 있다고 변경 이력이 밝히지만, 안내 문서(`code.claude.com/docs/en/code-mode`)는 확인 시점에 열리지 않아 설정 이름은 확인 불가입니다.

플러그인은 `plugin.json`에 `engines["claude-code"]`로 지원 버전 범위를 적을 수 있게 됐고, 범위를 벗어나면 설치·갱신·로드되지 않습니다. `claude plugin validate`가 TypeScript 훅 모듈의 타입도 검사합니다(`--strict`면 실패 처리).

그 밖에 `/compact`가 아직 답하지 않은 메시지를 요약해 없애던 문제, 비스트리밍 요청이 스트리밍이면 복구되던 오류에서 실패하던 문제, MCP 도구 호출이 `TOKEN_EXPIRED` 같은 인증 서버 오류로 끝나던 문제가 고쳐졌습니다. `Bash(PORT=* npm run dev)`처럼 변수 값에 `*`가 들어간 허용 규칙에는 시작할 때 경고가 뜹니다.

> 팀 플러그인을 배포하고 있다면 `plugin.json`에 `engines["claude-code"]`를 적어 오래된 Claude Code에 설치되지 않게 하세요. `settings.json`의 Bash 허용 규칙에 변수 와일드카드가 있다면 의도보다 넓게 허용하는지 점검하세요.

- 발표: 2026-11-13 · [Claude Code 변경 이력](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### 5. 자체 호스팅 Claude Managed Agents

Claude Platform 릴리스 노트 11월 12일 항목에 따르면 Managed Agents 서비스 전체(API, 에이전트 루프, 세션 기록 저장)를 자체 인프라에서 돌릴 수 있게 됐습니다. 지금까지는 도구가 실행되는 샌드박스만 직접 둘 수 있었습니다. 접근은 Anthropic 계정 팀에 요청해야 합니다.

서버(`cma-server`)는 PostgreSQL 16 이상을 저장소로 쓰고, 모델 호출은 기본 Claude API 외에 Amazon Bedrock, Google Cloud, Microsoft Foundry, 자체 모델 게이트웨이로 보낼 수 있습니다. 같은 API라서 SDK와 `ant` CLI가 그대로 붙습니다. 문서는 워커의 `bash` 도구가 격리 없는 실제 셸이니 일회용 컨테이너나 VM에서 돌리라고 경고합니다.

> 세션 기록을 사내에 둬야 해서 Managed Agents를 못 쓰던 팀이라면 검토할 만합니다. 서버 보안, 릴리스 설치, 이상 사용 탐지가 모두 운영 측 책임으로 넘어오니 운영 부담을 함께 따져 보세요.

- 발표: 2026-11-12 · [Claude Platform 릴리스 노트](https://platform.claude.com/docs/en/release-notes/overview) · [Self-hosted Claude Managed Agents 문서](https://platform.claude.com/docs/en/managed-agents/self-hosted)
