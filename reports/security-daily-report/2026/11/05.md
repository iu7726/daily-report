## 7. 공급망·CI/CD·인프라

### ④ [P2] screenshot-desktop 1.16.0 — GitHub 악성 판정, 메인테이너는 오탐이라고 반박

주간 다운로드 약 6만 6천 건인 화면 캡처 패키지 `screenshot-desktop`의 1.16.0이 11월 4일 20:26 KST에 게시됐고, 1시간 반 뒤 GitHub 보안 DB가 악성 코드 포함으로 판정했습니다. 권고는 설치한 컴퓨터를 완전히 장악된 것으로 보고 비밀 값을 모두 교체하라고 안내하지만, 악성 동작이 무엇인지는 밝히지 않았습니다.

1.16.0은 지금 npm에서 내려가 있고 `latest`는 1.15.8입니다. 메인테이너는 GitHub 이슈에서 태그 소스에는 이상한 변경이 없지만 원래 tarball을 받을 수 없어 확인하지 못했다며 권고를 "미해결"로 다루고 있습니다. JFrog 연구팀과 다른 사용자는 미러에 남은 tarball이 태그와 같다며 오탐이라고 주장합니다. 누가 왜 내렸는지는 확인 불가입니다.

1.16.0이 실제로 설치된 경우만 해당합니다. 게시 후 내려가기까지 짧은 시간이었고, 1.15.8 이하는 해당하지 않습니다.

> lockfile에 `screenshot-desktop@1.16.0`이 있다면 오탐 여부가 정리될 때까지 권고대로 그 머신의 토큰과 키를 다른 컴퓨터에서 교체하는 쪽이 안전합니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| 1.16.0 | 없음 (1.15.8로 고정) | GHSA-q2mc-9hgr-vmx2 · MAL-2026-18624 | 해당 없음 | 악성 동작 확인 불가, 오탐 논란 중 |

- `npm ls screenshot-desktop`과 CI 설치 로그에서 1.16.0을 찾습니다. 있으면 1.15.8로 고정하고 다시 설치합니다.
- Electron 앱처럼 이 패키지를 쓰는 배포물을 11월 4일 저녁에 빌드했다면 그 빌드도 확인합니다.
- 원문: [GitHub 권고 GHSA-q2mc-9hgr-vmx2](https://github.com/advisories/GHSA-q2mc-9hgr-vmx2) (2026-11-04) · [OSV MAL-2026-18624](https://osv.dev/vulnerability/MAL-2026-18624) · [메인테이너 이슈 #363](https://github.com/bencevans/screenshot-desktop/issues/363)
