### 1. NestJS 12.6.1·12.6.2 — Fastify 어댑터 Node.js 요구 버전 상향, 파이프 검증 강화

11월 25일 17:34 KST에 12.6.1, 23:07 KST에 12.6.2가 npm에 올라왔습니다(11.x에는 11.2.12). 12.6.1은 `@fastify/middie`를 9.3.9로 올리면서 Fastify 어댑터가 Node.js 20.19+ 또는 22.12+를 요구하게 됐습니다. 11.2.12 릴리스 노트는 그보다 낮은 20.x·22.x에서 `ERR_REQUIRE_ESM`으로 실패한다고 적었습니다.

검증도 엄격해졌습니다. `ParseDatePipe`는 `new Date()`가 다음 달로 넘겨 버리던 날짜(예: 2월 30일)를 숫자·월 이름·두 자리 연도 형식에서 더 많이 거부하고, 12.6.2에서는 연도 없는 2월 29일도 거부합니다.

| 버전 | 주요 변경 |
|---|---|
| 12.6.1 | RabbitMQ 서버 `nackOnInternalError` 옵션(기본 `false`), `ParseEnumPipe` 정확 일치 우선, `ConsoleLogger` 민감 정보 가림 범위 확대(`Headers`, `URLSearchParams`, `FormData`, URL 인증 정보) |
| 12.6.1 | Express에서 프로토타입 키를 건드리는 multipart 필드 이름은 400, 업로드 한도 `NaN`은 기본값으로 |
| 12.6.2 | `applyDecorators()` 타입 검사 복구, Node 어댑터 `res.send()`가 스트림을 `application/octet-stream`으로 전송, 204·205·304 `StreamableFile`은 본문 없이 응답 |
| 11.2.12 | `@fastify/middie` 9.3.8·9.3.9 반영, 같은 Node.js 요구 버전 |

> `@nestjs/platform-fastify`를 쓰는 서비스는 런타임과 CI 이미지의 Node 버전이 20.19 또는 22.12 이상인지 먼저 확인하세요. 날짜를 `ParseDatePipe`로 받는 API는 이전에 통과하던 잘못된 날짜가 이제 400을 받으니, 클라이언트가 그런 값을 보내고 있지 않은지 테스트로 확인한 뒤 올리세요.

- 발표: 2026-11-25 · [v12.6.1 릴리스](https://github.com/nestjs/nest/releases/tag/v12.6.1) · [NestJS 릴리스 목록](https://github.com/nestjs/nest/releases)

### 2. Claude Code 2.1.332 — MCP 서버 스킬(베타), `PreSkillShellCommand` 훅

어제 npm에만 올라왔던 2.1.332의 변경 이력이 공개됐고, npm `latest` 태그도 2.1.332로 옮겨졌습니다. MCP 서버가 제공하는 스킬을 쓸 수 있게 됐고(베타), `/` 메뉴에 `server:skill` 형식으로 보입니다.

새 훅 이벤트 `PreSkillShellCommand`는 스킬이나 명령이 불러올 때 실행하려는 셸 명령을 거부할 수 있습니다. 2.1.331 이하에서 이 훅을 적은 설정 파일을 열면 시작할 때 대화상자가 뜹니다.

| 변경 | 내용 |
|---|---|
| SSE MCP 서버 | 이벤트 스트림이 끊긴 뒤 멈추거나 모든 도구 호출을 거부하던 문제 수정 |
| 로컬 MCP 서버 | 표준 출력을 쏟아낼 때 터미널이 멈추고 Ctrl+C가 안 먹던 문제 수정 |
| MCP 작업 ID | 128자 넘는 task ID로 "malformed task handle" 오류 나던 문제 수정(1,024자까지 허용) |
| 파일 읽기 | 쓰는 쪽이 없는 named pipe(잠긴 시크릿 관리자가 마운트한 `.env` 등)에서 멈추지 않고 20초 뒤 실패 |
| `claude auth login` | 로그인 정보를 저장하지 못하면 성공이라 표시하지 않고 종료 코드 1 반환 |
| Bedrock Mantle | `sonnet` 별칭이 Haiku 4.5가 아니라 Sonnet 5를 가리킴 |

> 사내 MCP 서버를 SSE로 붙여 쓰거나 시크릿 관리자로 `.env`를 마운트하는 환경이라면 이 버전으로 올리세요. 외부 스킬을 들여오는 팀은 `PreSkillShellCommand` 훅으로 스킬이 실행하는 셸 명령을 검사하는 규칙을 둘 수 있습니다. 다만 2.1.331 이하가 섞인 팀은 설정 공유 전에 버전을 맞추세요.

- 발표: 2026-11-24(npm 게시, 미국 날짜), 변경 이력은 확인 기간 중 공개 · [Claude Code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### `skill-creator` (anthropics/skills)

새 스킬을 만들거나 기존 스킬을 고치고, 효과를 측정하게 돕는 스킬입니다. 의도 파악, 초안 작성, 테스트 프롬프트 작성, 스킬이 있을 때와 없을 때 결과 비교, 피드백 반영을 반복합니다. 결과는 `eval-viewer/generate_review.py`로 브라우저 리뷰 화면을 만들어 보여 줍니다.

마지막 단계로 설명문 최적화가 있습니다. 스킬이 불려야 할 질문과 불리지 말아야 할 질문 20개로 최대 5회 반복해 `description`을 다듬습니다.
