### ① [긴급] Node.js — Brotli 디코더 메모리 손상 취약점

- **공개일: 2026-10-21 | CVE-2026-111497**

Node.js에 포함된 Brotli 디코더에서 Out-of-Bounds Write 취약점이 발견됐다.

공격자가 조작한 Brotli 압축 데이터를 애플리케이션이 `node:zlib`로 압축 해제할 경우, 프로세스 메모리가 손상될 수 있다.

잠재적 영향은 프로세스 충돌, 메모리 정보 노출, 원격 코드 실행이다.

| Node.js 버전 계열 | 수정 버전 |
|---|---|
| 22.x | **22.23.4** |
| 24.x | **24.22.1** |
| 26.x | **26.12.1** |

이번 릴리스에는 DNS의 NULL 바이트 처리 오류(CVE-2026-105482), TLS 인증서 호스트명 검증 우회(CVE-2026-105483, CVE-2026-106069) 등도 포함됐다.

Node.js 프로젝트는 이번 릴리스의 최고 심각도를 **High**로 분류했다.

**실무 영향:** NestJS·Express 서버 자체가 항상 공격 가능한 것은 아니다. 외부에서 유입되는 Brotli 데이터를 처리하는지, 취약한 TLS·DNS 기능을 사용하는지 확인해야 한다. 다만 여러 문제가 함께 수정됐으므로 Node.js 런타임 업데이트를 우선 권장한다.

원문: [Node.js 공식 보안 릴리스](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) ([Node.js](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases))

### ② [긴급] GitLab — 인증 없는 원격 코드 실행

- **공개일: 2026-10-21 | CVE-2026-110264 | CVSS 10.0**

GitLab CE/EE의 정규식 컴파일 과정에서 정수 오버플로 취약점이 발견됐다.

특정 조건에서 공격자가 조작된 정규식으로 **인증 없이 서버에서 임의 코드를 실행할 가능성**이 있다.

GitLab이 제공한 수정 버전은 다음과 같다.

`18.11.13 / 19.0.10 / 19.1.9 / 19.2.9 / 19.3.6 / 19.4.3 / 19.5.1`

영향 범위는 GitLab 7.0 이후의 상당수 구버전까지 포함한다.

이번 패치에는 LDAP 계정 탈취 가능성(CVE-2026-15723), OIDC 메타데이터 캐시 오염(CVE-2026-112212) 문제도 포함됐다.

**실무 영향:** GitLab을 직접 운영한다면 우선순위가 매우 높다. GitLab 서버 침해는 소스코드뿐 아니라 CI/CD 토큰과 배포 자격 증명까지 영향을 줄 수 있다.

GitLab.com과 GitLab Dedicated는 이미 패치됐다고 공식 발표했다. 실제 악용 성공 사례는 해당 공지에서 확인되지 않았지만, GitLab은 공격 시도 탐지 방법을 제공하고 있다.

원문: [GitLab Critical Patch Release](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-5-1-released) ([GitLab Docs](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-5-1-released))

### ③ [긴급] React / Next.js — 인증 없는 RCE

- **최초 공개: 2026-10-14 | GitHub 취약점 DB 업데이트: 10-22**

두 가지 주요 RCE 문제가 확인됐다.

**A. React Server Components**

`GHSA-xqc2-xf4c-x3h3` — CVSS v4.0 **9.5**

공격자가 제어하는 값과 여러 TypedArray를 전송하는 특정 React Server Components 환경에서 RCE가 가능하다.

관련 패키지:

- `react-server-dom-webpack`
- `react-server-dom-parcel`
- `react-server-dom-turbopack`

패치 버전은 **19.0.9 / 19.1.10 / 19.2.9 / 19.3.1**이다.

React Server Components를 사용하지 않는 클라이언트 전용 React 애플리케이션은 이 취약점의 영향을 받지 않는다. ([GitHub](https://github.com/react/react/security/advisories/GHSA-xqc2-xf4c-x3h3))

**B. Next.js**

`GHSA-673q-mjm6-r5xr` — CVSS v4.0 **9.5**

App Router에서 Cache Components를 사용하며 `use cache` 함수가 여러 TypedArray를 반환하는 경우 RCE가 발생할 수 있다.

별도의 취약점인 `CVE-2026-96889`는 glibc 기반 Linux에서 이미지 최적화에 사용되는 라이브러리 문제로 RCE가 가능하다.

수정 버전:

| Next.js 계열 | 수정 버전 |
|---|---|
| 15.5.x | **15.5.28** |
| 16.4.x | **16.4.1** |

이미지 최적화 문제는 `sharp >= 0.35.5` 사용도 완화 방법으로 제시됐다.

**실무 영향:** Next.js 앱을 운영한다면 가장 먼저 프레임워크 버전을 확인해야 한다. 기존 프로젝트에 구버전 React Server Components 패키지가 간접 의존성으로 포함되어 있는지도 점검할 필요가 있다.

원문: [Next.js 공식 보안 업데이트](https://nextjs.org/blog/nextjs-security-update-october-14-2026) ([GitHub](https://github.com/vercel/next.js/security/advisories/GHSA-673q-mjm6-r5xr))

**실무 영향:** npm 패키지 공급망을 통한 침해는 개발자 PC, CI/CD Runner, 클라우드 인증 정보까지 연결될 수 있다.

### ⑤ [높음] AWS — Multi Model Server에서 RCE·SSRF 취약점

- **공개일: 2026-10-23, 미국 PDT 기준**
- **한국 시간: 10월 24일 02:30**

AWS가 공개했던 오픈소스 모델 서빙 도구 Multi Model Server(MMS)에서 두 취약점이 발견됐다.

| CVE | 취약점 | 영향 |
|---|---|---|
| CVE-2026-115812 | 모델 압축파일 경로 조작 | 임의 파일 쓰기 및 코드 실행 가능 |
| CVE-2026-115813 | 모델 다운로드 URL 처리 | SSRF 가능 |

**영향 버전:** 1.1.11 이하 전체

특히 관리 인터페이스에 인증 기능이 없으므로 외부 네트워크에 노출된 배포 환경은 위험도가 높다.

**중요한 점은 수정 버전이 없다는 것이다.**

MMS는 유지보수가 종료됐으며 AWS는 지원되는 모델 서빙 솔루션으로 이전할 것을 권고했다.

임시로 관리 인터페이스를 신뢰할 수 있는 네트워크에 제한할 수 있지만, 모든 배포 구성에서 가능한 것은 아니다.

원문: [AWS Security Bulletin 2026-148](https://aws.amazon.com/security/security-bulletins/2026-148-aws/) ([Amazon Web Services, Inc.](https://aws.amazon.com/security/security-bulletins/2026-148-aws/))

### ⑥ [높음] PHP — 새로운 RCE 경로 공지

- **공개일: 2026-10-23 | CVE-2026-115560**

PHP 보안팀이 Session Upload Progress 기능과 관련된 추가 보안 공지를 발표했다.

특정 설정 조합에서 RCE가 발생할 수 있다는 내용이다.

공격 조건은 상당히 제한적이다.

`session.serialize_handler`가 `php_binary` 또는 `php_serialize`로 설정된 상태에서, 애플리케이션이 런타임에 이를 `php`로 변경하고 Session Upload Progress 기능도 활성화되어 있어야 한다.

현재 해당 문제의 정식 수정판은 발표되지 않았다.

**임시 대응**

```ini
session.upload_progress.enabled=0
```

PHP 보안팀은 다음 정기 수정 릴리스까지 이 설정을 권고했다.

한편, 10월 21일 공개된 별개의 치명적 RCE 두 건인 `CVE-2026-109618`, `CVE-2026-109619`는 이미 수정됐다.

수정 버전은 **PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35**다.

**실무 영향:** 순수 Node.js 환경에는 직접적인 영향이 없다. 다만 별도 WordPress 서버나 PHP-FPM을 사용하는 서비스가 있다면 점검 대상이다.

원문: [PHP 공식 보안 공지](https://www.php.net/archive/2026.php) ([PHP](https://www.php.net/archive/2026.php))

Redis는 기존 `CVE-2026-81934`의 수정판 적용 여부를 확인하는 편이 좋다. PostgreSQL 14는 2026년 11월 지원 종료가 예정되어 있어 사용 중이라면 업그레이드 계획을 잡을 필요가 있다. ([Redis](https://redis.io/blog/security-advisory-cve-2026-81934/))

Nginx는 10월 14일 발표된 5건의 취약점이 **1.30.6(stable), 1.31.7(mainline)**에서 수정됐다. 10월 21일에는 mainline 1.31.8도 출시됐다. `alias`와 `rewrite` 조합, HTTP/3, TLS 세션 티켓 등의 설정을 사용하는 서버라면 버전 확인을 권장한다. ([Nginx](https://nginx.org/))

## 3. AWS·AI 개발 도구 관련 추가 이슈

이번 주에는 AI 에이전트와 클라우드 개발 도구 관련 보안 이슈도 확인됐다.

| 대상 | CVE | 취약점 및 영향 | 대응 |
|---|---|---|---|
| **AWS MCP Server** | CVE-2026-115845 | `run_script` Python 샌드박스 검증 오류로 인증된 사용자가 자신의 격리 세션에서 임의 코드 실행 가능 | **AWS 측 수정 완료. 사용자 조치 불필요** |
| **Strands Agents SDK** | CVE-2026-115419 | 멀티테넌트 A2A 서버에서 다른 세션의 대화 정보 노출·간섭 가능 | TypeScript SDK **1.5.0+**, Python **1.43.0+** |
| **AWS SAM CLI** | CVE-2026-115414 | Terraform Hook에 명령어 주입. 공격자가 빌드 입력을 조작할 수 있어야 함 | **1.166.2+** 업데이트 |

특히 Strands Agents의 TypeScript SDK인 `@strands-agents/sdk`는 **1.5.0 미만**이 영향 대상이다.

AWS SAM CLI는 **1.63.0~1.166.1**에서 `sam build --hook-name terraform`을 사용할 때 문제가 될 수 있다. 외부에서 전달된 Terraform 설정·Plan 파일을 CI에서 처리하는 구조라면 확인해야 한다.

이 중 AWS MCP Server 문제는 **Claude Code 자체의 보안 취약점이 아니다.** AWS가 제공하는 관리형 MCP 서버에서 발견된 문제다. ([Amazon Web Services, Inc.](https://aws.amazon.com/security/security-bulletins/2026-149-aws/))

## 4. 오늘 확인하면 좋은 명령어

Node.js와 Next.js 프로젝트에서는 우선 다음 항목을 확인하면 된다.

```bash
# Node.js 런타임 버전
node -v

# Next.js / React Server Components 의존성
npm ls next react \
  react-server-dom-webpack \
  react-server-dom-turbopack \
  react-server-dom-parcel

# 신규 악성 패키지 설치 여부
npm ls --all @grabcad/user-license \
  @ecg-internal/media-util-js-lib

# 일반적인 의존성 취약점 검사
npm audit
```

서버와 CI 환경에서는 다음 항목을 추가로 확인한다.

```bash
# Nginx 버전
nginx -v

# AWS SAM CLI 버전
sam --version

# AWS Strands Agents SDK
npm ls @strands-agents/sdk

# PHP 서버가 있는 경우
php -v
```

`npm audit`는 모든 악성 패키지를 탐지하는 도구가 아니므로, 악성 패키지 경고는 **lockfile·설치 이력·CI 캐시**까지 확인해야 한다.
