### 1. NestJS 12.6.3 — 라우트 충돌 판정, `@Body('key')`, 버전 제외 동작 변경

11월 26일 20:07 KST(npm 게시)에 NestJS 12.6.3이 나왔습니다. 그제 12.6.1·12.6.2에 이어 사흘째 패치인데, 릴리스 노트에 "동작 변경(Behaviour Changes)" 절이 따로 있습니다.

가장 눈여겨볼 것은 라우트 충돌 판정입니다. 이제 라우터가 실제로 경로를 맞추는 방식대로 충돌을 검사해서, Express와 `caseSensitive: false`인 Fastify에서는 `GET /users`와 `GET /Users`를 같은 라우트로 봅니다. `duplicate: 'error'`를 켰다면 부팅이 중단됩니다.

| 영역 | 바뀐 동작 |
|---|---|
| `@Body('key')` | 본문이 `""`, `0`, `false` 같은 거짓 값이면 본문 전체가 아니라 `undefined`를 받음 |
| 버전 제외 | `MiddlewareConsumer.exclude()`·`enableCsrfProtection()`의 `exclude`에서 버전 없이 뺀 경로가 기본 버전 라우트에도 적용 |
| `ParseDatePipe` | 연도 없는 숫자 날짜(`2/30`, `2/29`)와 `Thu 2024 Sept 31` 형식에서 월말을 넘는 날짜 거부 |
| `GrpcExceptionFilter` | `RpcException`이 아닌 오류를 `UNKNOWN`으로 응답하기 전에 로그로 남김 |
| 보안 헤더 | `referrerPolicy.policy`에 `undefined` 항목이 있으면 거부 |
| 404 성능 | 매칭되지 않은 경로의 404를 스택 추적 없이 만들어 요청당 CPU 시간 28 ~ 29% 감소 |
| Fastify | `listen(port, host, backlog)`의 backlog 전달 수정, 본문 전송 중 클라이언트가 끊으면 400, 304 응답의 `StreamableFile`은 파일을 읽지 않음 |
| WebSocket | `events`와 `/events/`처럼 표기만 다른 게이트웨이가 한 서버를 공유 |
| 테스트 | `Test.createTestingModule()`이 `instrument` 옵션을 받음 |

> `duplicate: 'error'`를 쓰는 서비스는 올리기 전에 앱을 한 번 띄워 대소문자만 다른 라우트가 없는지 확인하세요. 버전 없이 미들웨어나 CSRF 제외 경로를 지정했다면 기본 버전 라우트에서도 미들웨어가 빠지니, 인증·CSRF 미들웨어가 의도대로 걸리는지 e2e 테스트로 확인해야 합니다.

- 발표: 2026-11-26 · [v12.6.3 릴리스](https://github.com/nestjs/nest/releases/tag/v12.6.3)

### 2. OpenAI Node SDK `openai` 7.65.0 — 지출 한도 알림, 세션 vault 갱신

11월 26일 16:24 KST(npm 게시)에 `openai` 7.65.0이 나왔습니다. 조직·프로젝트 지출 한도(hard spend limit)에 이메일 알림 설정이 붙었고, 대화 생성과 응답 압축(compaction) 요청에 safety identifier를 넣을 수 있게 됐습니다.

Managed Agents 세션 갱신에는 `vault_ids`가 추가됐습니다. 값을 주면 세션의 vault 참조를 통째로 바꾸고, 빼면 그대로 두며, `null`이나 빈 배열이면 모두 지웁니다. API 변경 이력에는 11월 24일 항목 이후 새 글이 없습니다.

> Managed Agents 세션을 갱신하는 코드에서 `vault_ids`를 빈 배열로 넘기면 기존 vault 연결이 모두 끊깁니다. 일부만 바꾸려면 기존 목록을 읽어 합친 뒤 넘기세요. 일반 Responses 호출만 쓴다면 급히 올리지 않아도 됩니다.

- 발표: 2026-11-26 · [openai-node CHANGELOG](https://github.com/openai/openai-node/blob/master/CHANGELOG.md) · [PR #3194](https://github.com/openai/openai-node/pull/3194) · [PR #3196](https://github.com/openai/openai-node/pull/3196)

### 3. Qwen Code 0.28.6·0.28.7 — 반복 감지·도구 호출 상한 제거

Qwen Code가 하루에 두 번 정식판을 냈습니다(0.28.6은 11월 26일 14:06 KST, 0.28.7은 11월 27일 03:58 KST npm 게시). 두 버전 모두 호환성을 깨는 변경을 하나씩 담았습니다.

0.28.7은 모델 반복 감지와 도구 호출 상한을 없앴습니다. 도구 결과와 오류가 가공 없이 모델에 그대로 전달됩니다. 0.28.6은 ACP 답변을 다시 쓰던 별도 모델 호출(`MessageRewriteMiddleware`)을 없애고 훅 방식으로 바꿨습니다.

| 버전 | 그 밖의 변경 |
|---|---|
| 0.28.6 | 셸 명령 실행 중 프롬프트를 보내면 명령을 멈추지 않고 백그라운드로 보냄, 컨텍스트 길이 초과 오류를 인식해 자동 압축 |
| 0.28.7 | 모델별 추론 강도·컨텍스트 창 설정 저장, CLI 사용 통계 기본 꺼짐, 워크트리 스냅샷 보관 개수 설정(`worktree.maxRetained`) |

> CI나 헤드리스 모드로 Qwen Code를 돌린다면 0.28.7부터는 도구가 같은 호출을 반복해도 CLI가 끊어 주지 않습니다. 작업 시간 제한이나 비용 상한을 파이프라인 쪽에 두고 올리세요.

- 발표: 2026-11-26 · [Qwen Code 릴리스](https://github.com/QwenLM/qwen-code/releases)
