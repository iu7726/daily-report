## 7. 공급망·CI/CD·인프라

### ① [P1] WPPConnect — npm 배포판 탈취, 비밀 값과 WhatsApp 세션 유출

WhatsApp Web 자동화 라이브러리 WPPConnect의 기본 브랜치에 관리자 계정으로 리뷰 없는 커밋이 올라갔고, 릴리스 워크플로가 그대로 npm에 배포했습니다. 악성 버전은 라이브러리를 불러오거나 서버를 켜는 순간 환경 변수, `.env`와 설정 파일, WhatsApp 세션 토큰 파일, 공인 IP를 모아 Telegram 봇으로 보냅니다. 설치 스크립트가 아니라 실행 시점에 동작하므로 `--ignore-scripts`로는 막지 못합니다.

관리자가 이슈에서 악성 코드를 확인했고, npm `latest`를 2.4.0으로 되돌린 뒤 두 버전에 "SECURITY INCIDENT" 지원 중단 표시를 붙였습니다. 다만 계정 탈취 경로와 Telegram 자격 증명 폐기는 아직 확인되지 않았다며 이슈를 열어 두고 있습니다.

WPPConnect를 쓰지 않는 프로젝트는 해당하지 않습니다. 쓰더라도 2.4.0 이하·2.10.81 이하로 고정돼 있었다면 해당하지 않습니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| `@wppconnect-team/wppconnect` 2.4.1, `@wppconnect/server` 2.10.82 (Docker `wppconnect/wppconnect-server` 2.10.82·2.10.83 미확인 보도) | 없음(2.4.0, 2.10.81로 고정) | CVE 없음, GitHub 권고 확인 불가 | 해당 없음 | 악성 코드 배포 확인(관리자 확인), KEV 아님 |

> 2.4.1은 11월 16일 08:31 ~ 13:03 KST에 `latest`였습니다. 이 시간에 `^2.4.0` 범위로 설치·빌드한 PC, CI, 컨테이너가 있다면 거기 있던 비밀 값을 모두 다른 기기에서 교체하고 WhatsApp 세션을 로그아웃해야 합니다.
