### ① Anthropic — Claude API 신규 버전 `2026-10-21` 출시
**발표: 10월 21일 | 중요도: 매우 높음 | 백엔드 관련**

오늘 가장 중요한 소식입니다.

Anthropic이 기존 `2023-06-01` API 버전 이후 새로운 버전인 **`2026-10-21`**을 공개했습니다.

이번 변경은 단순 기능 추가가 아니라 기존 API 요청을 실패하게 만들 수 있는 Breaking Change를 포함합니다.

| 변경 항목 | 내용 | 영향 |
|---|---|---|
| `temperature` | 지원 제거 | 요청 시 HTTP 400 |
| `top_p` | 지원 제거 | 요청 시 HTTP 400 |
| `top_k` | 지원 제거 | 요청 시 HTTP 400 |
| Assistant의 Document Block | 직접 전달 제한 | 해당 요청 HTTP 400 |
| User 메시지의 Citation | 비어 있지 않은 Citation 배열 제한 | 해당 요청 HTTP 400 |
| Admin API | 응답 필드명 변경 | 기존 파싱 로직 수정 필요 |

특히 `temperature`, `top_p`, `top_k`를 제거한 점이 중요합니다.

이전에는 모델의 출력 다양성을 조정할 수 있었지만, 새 API 버전에서는 해당 파라미터를 사용할 수 없습니다. 기본값으로 동작하도록 변경되며, 비기본값으로 조정하던 일부 구형 모델의 출력 특성이 달라질 수 있습니다.

**TypeScript SDK도 `1.0.0`으로 업데이트**되면서 새로운 API 버전을 기본으로 사용합니다. Python SDK는 `2.0.0`입니다.

이전 API 버전을 사용하던 코드가 즉시 중단되는 것은 아니지만, SDK의 메이저 버전을 올릴 때 기존 코드와 호환성을 반드시 확인해야 합니다.

**NestJS 개발자 관점:** Anthropic API를 직접 호출하는 서비스라면 SDK 버전을 고정하고, 업그레이드 전 요청 파라미터와 응답 처리 로직을 검증하는 것이 좋겠습니다.

기존 Claude가 사용자의 요청에 응답하는 방식이었다면, Duet은 연결된 서비스를 주기적으로 확인하고 먼저 행동을 제안하는 **상시 작동형 에이전트**입니다.

### ⑥ Claude Code — v2.1.307 출시
**릴리스: 10월 22일 07:17 KST | 중요도: 높음**

Claude Code가 `v2.1.307`로 업데이트됐습니다.

이번 버전은 API 마이그레이션과 MCP 안정성 개선이 중심입니다.

**주요 변경 사항**

- `/claude-api api-version`: Claude API 신규 버전으로 마이그레이션 지원
- `claude_code.safety_event`: 권한·보안 검사에 의해 도구 호출이 차단되거나 승인을 요청한 이력을 OpenTelemetry 이벤트로 기록
- HTTP MCP 연결이 중간에 종료될 경우, 읽기 전용 또는 멱등성을 가진 도구 호출만 재시도
- MCP 서버 인증 및 연결 타임아웃 관련 오류 수정
- 대용량 도구 응답 처리 시 Autocompact 안정성 개선

**멱등성이 보장되지 않는 MCP 호출을 무조건 재시도하면 중복 데이터 생성이나 중복 결제가 발생할 수 있습니다.**

또한 `v2.1.306`에서는 클라우드 세션의 인증 문제와 다수의 MCP 도구를 사용할 때 API 오류가 잘못 처리되던 문제를 수정했습니다.
