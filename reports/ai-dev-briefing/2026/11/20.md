### 1. Gemini Interactions API 도구 검색 미리 보기, Genie 4 정식 출시

Google이 11월 19일(미국 날짜) Gemini API 변경 이력에 도구 검색을 미리 보기로 올렸습니다. 도구 목록 전체를 매 요청에 보내지 않고, 모델이 필요한 함수 스키마만 찾아 불러옵니다. 도구에 `defer_loading: true`를 붙이고 `{"type": "tool_search"}` 도구를 추가하면 Gemini가 검색하고, `execution: "client"`로 두면 검색 로직을 직접 구현할 수 있습니다.

원격 MCP 서버도 `defer_loading`을 지원합니다. Gemini 3.6 이후 모델과 모든 Gemini 4 모델에서 동작합니다. 공개 SDK 쪽 타입은 어제 다룬 `@google/genai` 3.6.0에 이미 들어가 있습니다.

같은 날 실시간 인터랙티브 월드 생성 모델 Genie 4(`models/genie-4`)도 Interactions API(`v1beta`)에 정식 출시됐습니다. 유료 등급 기준 100만 토큰당 입력 $1.50, 텍스트 출력 $9.00, 영상 출력 $17.50(초당 약 $0.10)입니다.

> 내부 API 수십 개를 함수 도구로 노출하는 NestJS 에이전트라면 자주 쓰지 않는 도구에 `defer_loading: true`를 붙여 입력 토큰을 줄일 수 있습니다. 미리 보기 기능이니 운영 경로에 넣기 전에 도구 선택 정확도가 떨어지지 않는지 기존 요청 로그로 비교해 보세요.

- 발표: 2026-11-19(미국 날짜) · [Gemini API 변경 이력](https://aistudio.google.com/docs/changelog)

### 2. Claude Code 2.1.328·2.1.329 — 설정 파일 초기화 수정, `mcp_tool` 훅 실패 시 차단

2.1.328은 11월 19일 08:09 KST에 npm에 올라왔지만, 어제 보고 시점에는 변경 이력이 없어 내용을 확인하지 못했습니다. 2.1.329는 11월 20일 03:40 KST에 게시됐습니다. 두 버전의 Agent SDK는 0.3.328, 0.3.329입니다.

2.1.329에서는 네트워크 지연이나 파일 잠금으로 `~/.claude.json`을 읽지 못한 채 저장하면 설정이 기본값으로 초기화되던 문제가 고쳐졌습니다. macOS에서 키체인을 읽을 수는 있지만 저장할 수 없을 때 반복해서 로그아웃되던 문제도 고쳐졌습니다. 폴더 신뢰 창에는 그 폴더의 훅이 어디에 선언됐는지 경고가 붙습니다.

| 버전 | 주요 변경 |
|---|---|
| 2.1.328 | `mcp_tool` 훅에 `"onFailure": "block"` 추가 (훅 호출이 실패하면 동작 차단) |
| 2.1.328 | `CLAUDE_STREAM_IDLE_TIMEOUT_MS`가 게이트웨이·사용자 지정 base URL에서 5분 연결 제한을 늘리지 못하던 문제 수정 |

| 2.1.328 | 서드파티 제공자에서 입력 스키마가 `anyOf`·`oneOf`·`allOf`로 시작하는 MCP 도구가 사라지던 문제 수정 |
| 2.1.329 | `/mcp` 서버 화면에 원격 HTTP MCP 서버가 연결을 거부한 JSON-RPC 오류 메시지 표시 |

### 3. `@anthropic-ai/sdk` 1.11.0 — Admin API로 Claude Code 관리 설정

11월 20일 04:29 KST(npm 게시)에 TypeScript SDK 1.11.0이 나왔습니다. Admin API에 Claude Code 관리 설정(managed settings)이 추가됐고, Admin API 플러그인 메서드에 `sandbox_egress_restricted` 오류가 생겼습니다. 큰 스트리밍 이벤트 처리 속도도 개선됐습니다.

Claude Platform 릴리스 노트에는 11월 17일 Linked billing 이후 새 항목이 없어, 관리 설정 API의 세부 동작은 SDK 변경 이력 말고는 확인 불가입니다.

> 팀의 Claude Code 권한·훅 정책을 사람이 콘솔에서 바꾸고 있다면, 이 SDK로 정책을 코드로 관리하는 스크립트를 만들 수 있는지 검토해 볼 만합니다. 큰 도구 결과를 스트리밍으로 받는 Node 서비스는 1.11.0으로 올리면 처리 속도 개선을 바로 얻습니다.

- 발표: 2026-11-19 · [CHANGELOG](https://github.com/anthropics/anthropic-sdk-typescript/blob/main/CHANGELOG.md)

### 4. OpenAI GPT-Live-1.1, WebRTC 세션 대기 기능

OpenAI가 11월 19일(미국 날짜) API 변경 이력에 GPT-Live-1.1을 올렸습니다. 다국어 음성 대화의 발음, 억양 일관성, 받아쓰기 품질을 개선한 모델로, 기존 Live 세션 설정에서 모델을 `gpt-live-1.1`로 바꾸면 됩니다. GPT-Live-1과 1.1의 WebRTC 세션은 말이 없는 동안 추론을 멈췄다가 누군가 말하면 다시 시작하는 대기(standby)를 쓸 수 있습니다.

`openai` Node SDK 7.61.0(11월 20일 06:07 KST)에 `gpt-live-1.1`이 Live 모델 선택지로 추가됐습니다. 가격은 변경 이력에 적혀 있지 않아 확인 불가입니다.

> 한국어 음성 상담 같은 Live 기능을 Node 서버에서 붙이고 있다면 `openai` 7.61.0으로 올린 뒤 모델 이름만 바꿔 받아쓰기 품질을 비교해 볼 만합니다. 대기 시간이 긴 통화라면 standby로 유휴 구간 비용이 줄어드는지도 함께 확인하세요.

- 발표: 2026-11-19(미국 날짜) · [API 변경 이력](https://developers.openai.com/api/docs/changelog) · [openai-node CHANGELOG](https://github.com/openai/openai-node/blob/master/CHANGELOG.md)

### 5. Gemini CLI 0.69.0·0.70.0 — 안전하지 않은 MCP 서버 건너뛰기, 정책 매칭 보강

Gemini CLI가 11월 19일 10:51 KST에 0.69.0, 11월 20일 06:13 KST에 0.70.0을 정식 게시했습니다. 두 버전 모두 새 기능보다 보안·안정성 수정이 중심입니다.

0.70.0은 실행 명령 권한이 안전하지 않은 시스템 MCP 서버를 건너뜁니다. 정책의 `commandPrefix`·`commandRegex` 규칙은 최상위 명령 기준으로 맞추고, `argsPattern`은 re2js로 선형 시간에 평가합니다. 확장되지 않은 셸 변수가 남은 명령은 계속 사용자 확인을 거치고, 동의 창의 기본값은 "아니요"가 됐습니다.

0.69.0은 macOS Seatbelt 샌드박스에 들어가기 전에 폴더 신뢰를 먼저 판단하고, `tildeifyPath`의 경로 경계 검사를 고쳤습니다. 헤드리스 실행을 중단하면 하위 프로세스까지 종료되고, 몇 시간씩 이어지던 할당량 재시도도 고쳐졌습니다.

> CI에서 Gemini CLI를 헤드리스로 돌리며 정책 파일로 명령을 제한하고 있다면 0.70.0으로 올리고, `commandRegex` 규칙이 의도한 명령만 막는지 다시 확인하세요. 파이프나 `&&`로 묶인 명령의 매칭 결과가 이전과 달라질 수 있습니다.

- 발표: 2026-11-19 · [v0.69.0 릴리스](https://github.com/google-gemini/gemini-cli/releases/tag/v0.69.0) · [v0.70.0 릴리스](https://github.com/google-gemini/gemini-cli/releases/tag/v0.70.0)

### `grilling` (mattpocock/skills)

계획이나 설계를 놓고 에이전트가 사용자에게 집요하게 질문해, 설계 트리의 모든 갈래가 정해질 때까지 합의를 맞추는 스킬입니다. 질문을 번호 붙인 묶음으로 내고, 질문마다 추천 답을 함께 적은 뒤 답을 받고 나서 다음 묶음으로 넘어갑니다. 사용자가 직접 부르는 `grill-me`와 달리 모델이 스스로 꺼내 쓰는 스킬이고, `grill-me`, `grill-with-docs`, `triage`, `improve-codebase-architecture`가 이 스킬을 바탕으로 동작합니다.

| 항목 | 값 |
|---|---|
| 설치 수 | 1.1M (확인 2026-11-20 08:45 KST, skills.sh 표시값) |
| 처음 등록 | 2026-06-04(skills.sh 첫 확인일), 신규 아님 |
| 보안 감사 | Gen Agent Trust Hub·Socket·Snyk 모두 Pass |

- 원문: [skills.sh](https://skills.sh/mattpocock/skills/grilling) · [mattpocock/skills](https://github.com/mattpocock/skills)

> NestJS 모듈 경계나 DB 스키마를 바꾸기 전에 에이전트가 요구사항을 추측해 바로 코드를 쓰는 일을 줄여 줍니다. 셸 명령을 실행하지 않는 대화형 스킬이라 권한 부담은 작지만, 모델이 스스로 꺼내 쓰기 때문에 간단한 수정에서도 질문이 길어질 수 있습니다. `grill-me`를 이미 설치했다면 이 스킬이 함께 쓰이는지 먼저 확인하고 중복 설치하지 마세요.
