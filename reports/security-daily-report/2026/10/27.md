### ② AWS CDK — Redshift 관리자 권한으로 SQL Injection

- **High · CVSS v3.1 7.3**
- 2026-10-26 09:30 PDT 공개
- **CVE-2026-115418 / GHSA-25hh-xvj4-2cqv**

AWS CDK 실험적 모듈인 `@aws-cdk/aws-redshift-alpha`에서 사용자명·주석·비밀번호 같은 Construct 속성값이 SQL에 안전하게 반영되지 않는 문제가 발견됐다.

공격자가 CDK 속성값에 악성 입력을 주입할 수 있다면, 배포 과정에서 Redshift 슈퍼유저 권한으로 의도하지 않은 SQL이 실행될 수 있다. 심한 경우 전체 사용자에게 테이블 접근 권한이 부여될 수 있다.

| 항목 | 내용 |
|---|---|
| 영향 패키지 | `@aws-cdk/aws-redshift-alpha` |
| 취약 버전 | `2.274.0-alpha.0` 미만 |
| 수정 버전 | **2.274.0-alpha.0** 이상 |
| 공격 조건 | 공격자가 CDK Construct 속성값에 영향을 줄 수 있어야 함 |
| 실제 악용 | 공식적으로 확인되지 않음 |

**주의:** 이는 Redshift 서비스 전체의 인증 없는 SQL Injection이 아니다. 특정 CDK 모듈을 사용하면서 신뢰할 수 없는 값이 배포 설정에 들어가는 경우의 취약점이다.

패치 후에도 기존에 잘못 부여된 권한은 자동 회수되지 않으므로 Redshift의 `PUBLIC` 대상 GRANT를 검토해야 한다.

공식 원문: [AWS Security Bulletin 2026-151](https://aws.amazon.com/security/security-bulletins/2026-151-aws/) · [AWS CDK 보안 권고문](https://github.com/aws/aws-cdk/security/advisories/GHSA-25hh-xvj4-2cqv)
