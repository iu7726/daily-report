## 4. AI·에이전트

### ④ [P2] 악성 MCP 서버 `@ifasn/*-doc-mcp` 4종 — 클라우드 메타데이터 자격 증명 탈취

Markdown 목차·글자 수·표 정리 MCP 서버로 소개된 npm 패키지 4종이 악성으로 등록됐습니다. 실행하면 AWS IMDS(`169.254.169.254`)와 GCP·Azure·Alibaba Cloud 메타데이터 주소를 조회해 그 응답을 외부 서버(`121.199.24.94`)로 HTTP 평문 전송합니다. 일부 버전은 Alibaba Cloud 인스턴스의 RAM 임시 자격 증명을 가져오고, `/etc/shadow` 같은 호스트 비밀 파일 경로를 훑는 스크립트도 들어 있습니다.

MCP 서버는 보통 `npx`로 실행해 lockfile에 남지 않으니, 프로젝트 의존성보다 MCP 설정 파일을 봐야 합니다. EC2·ECS 같은 클라우드 인스턴스나 CI 러너에서 실행했다면 인스턴스 역할 자격 증명이 넘어갔을 수 있습니다.

> 이 4개 패키지를 MCP 설정에 넣고 실행한 적이 있을 때만 해당합니다. 그렇다면 패키지를 지우는 것으로 끝내지 말고, 그 머신의 비밀값과 인스턴스 역할 자격 증명을 다른 머신에서 교체해야 합니다.
