### 1. Claude Code 2.1.325 — 샌드박스·예약 작업 권한 동작 변경, 보안 수정

11월 14일 03:42 KST에 2.1.324, 05:07 KST에 2.1.325가 npm에 게시됐습니다. 변경 이력에는 2.1.325 항목 하나로 묶여 있습니다. 첫 줄이 zstd로 압축된 응답을 해석하는 부분의 보안 수정이고, 세부 내용은 공개되지 않았습니다.

권한 동작이 여럿 바뀌었습니다. 지금까지 그대로 돌던 명령이 확인 대기에서 멈출 수 있습니다.

| 바뀐 점 | 계속 묻지 않고 돌리려면 |
|---|---|
| 샌드박스 안의 Bash 명령도 일반 권한 흐름을 따름 | `sandbox.autoAllowBashIfSandboxed: true` |
| 예약 작업·`/loop`가 `allowed-tools`나 훅을 선언한 스킬 실행 전에 물음 | `permissions.allow`에 `Skill(name)` 추가 |
| 프로젝트·신뢰한 저장소가 아닌 곳의 읽기 전용 git 명령도 물음 | `--add-dir`로 지정 (`additionalDirectories` 설정은 해당 안 됨) |
| 데스크톱·IDE·SDK의 "Always allow"는 규칙이 실제로 다시 허용할 때만 규칙을 저장 | 예약 작업이 확인을 기다릴 수 있음 |

그 밖에 일부 복합 Bash 명령이 묻지 않고 실행되던 틈, Bash 허용 규칙이 이름과 다른 프로그램을 실행할 수 있던 문제, `cd` 뒤 `Read(./.env)` 같은 상대 경로 거부 규칙이 적용되지 않던 문제가 고쳐졌습니다. 샌드박스가 띄우는 보조 프로그램은 이제 로그인 토큰과 API 키 없이 실행됩니다.

> CI나 예약 작업에서 Claude Code로 테스트·빌드·린트를 돌리고 있다면 올린 뒤 한 번 실행해 확인 대기에서 멈추지 않는지 보고, 필요한 경우에만 위 설정을 명시하세요. 보안 수정이 있으니 버전 고정을 풀고 2.1.325로 올리는 쪽이 낫습니다.

### 3. Codex CLI 0.168.0·0.169.0 — `codex exec`의 신뢰 처리 변경

11월 13일 13:00 KST에 0.168.0, 17:43 KST에 0.169.0이 npm에 게시됐습니다. 0.169.0부터 `codex exec`는 신뢰하지 않은 폴더에서 `--sandbox workspace-write`를 줘도 프로젝트 설정과 MCP 서버를 쓰지 않습니다. 신뢰를 저장하려면 `--trust`를 명시해야 합니다.

0.168.0은 `features.multi_agent`를 직접 설정하면 경고를 띄우고 서브에이전트 도구를 끌 때 `agents.enabled`를 쓰라고 안내합니다. 터미널에서 커스텀 모델 제공자를 추가·편집하는 기능, 사이드 대화 탭(`features.tui_workspace`)도 들어왔습니다.

> CI에서 새로 받은 저장소에 `codex exec`를 돌리며 프로젝트의 `.codex` 설정이나 MCP 서버에 기대고 있다면 0.169.0에서 그 설정이 빠진 채 실행됩니다. 의도한 저장소에만 `--trust`를 붙이세요.

- 발표: 2026-11-13 · [Codex 0.169.0 릴리스](https://github.com/openai/codex/releases/tag/rust-v0.169.0) · [Codex 0.168.0 릴리스](https://github.com/openai/codex/releases/tag/rust-v0.168.0)

### 4. LangChain.js 1.6.6 — 도구 실패로 프로세스가 죽던 문제 수정

11월 14일 03:28 KST(npm 게시)에 `langchain` 1.6.6과 `@langchain/core` 1.4.1이 나왔습니다. 실패한 도구 호출이나 서브에이전트의 `output` 프로미스를 아무도 소비하지 않으면 처리되지 않은 거부로 프로세스가 죽던 문제가 고쳐졌습니다.

core 1.4.1은 스트리밍 중 `input_json_delta` 조각을 같은 인덱스의 `tool_use` 블록에 합칩니다. 함께 나온 `@langchain/anthropic` 1.6.5는 이 덕분에 스트리밍에서도 `withStructuredOutput`이 동작하고, `@langchain/google` 0.2.15는 `gemini-4-hydrogen` 프로필과 `xhigh` 생각 수준을 추가했습니다.

> NestJS 서버에서 LangChain.js 에이전트를 돌리다 도구 오류 뒤 프로세스가 재시작된 적이 있다면 이 버전으로 올리세요. 1.6.5와 마찬가지로 Zod 4.6.6 이상이 필요합니다.

- 발표: 2026-11-13 · [`langchain@1.6.6`](https://github.com/langchain-ai/langchainjs/releases/tag/langchain%401.6.6) · [`@langchain/core@1.4.1`](https://github.com/langchain-ai/langchainjs/releases/tag/%40langchain%2Fcore%401.4.1)

`grilling`은 결정을 서로 의존하는 트리로 보고, 선행 결정이 정해진 질문들을 한 번에 번호를 붙여 묻습니다. 질문마다 추천 답을 달아 "예"로 답하면 추천을 받아들이는 방식이고, 답을 받은 뒤 다음 단계 질문으로 넘어갑니다. skills.sh 설명에 따르면 코드에서 답을 찾을 수 있는 질문은 저장소를 읽어 확인합니다.
