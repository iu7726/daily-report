# 방문 통계 (Vercel Web Analytics) — 기획서

> 상태: **구현 완료 (2026-11-03)**. Vercel Analytics 켬(사용자), 배포 `v0.0.9`.
> 남은 것: 없음

## 0. TL;DR

GA 없이 방문 통계를 본다. 검색어·노출·순위는 이미 등록한 구글 서치 콘솔과 네이버 서치어드바이저로, 사이트 방문자(페이지별 조회수, 유입 경로, 국가)는 Vercel Web Analytics로 본다.

## 2. 현재 (2026-11-03)

- 방문 통계 도구 없음. 서치 콘솔·서치어드바이저는 11-02에 등록했다.
- 같은 날 GitHub 저장소가 구글에서 "보안 데일리 리포트" 1페이지에 노출됐다. 저장소 방문은 GitHub Insights → Traffic(최근 14일)에서 본다.

## 3. 결정 사항

### 확정 (사용자 2026-11-03)

- **D1. Vercel Web Analytics를 쓴다.** GA는 쓰지 않는다.

### 구현 방향

- **D2.** `@vercel/analytics` 2.0.1(2026-03 배포, 하위 의존성 없음)의 `<Analytics />`를 루트 레이아웃에 넣는다. 개발 모드에서는 수집하지 않는다.
- **D3. 비용**: Hobby 플랜은 월 5만 이벤트(페이지 조회 1회 = 1이벤트)까지 무료다. 넘으면 과금되지 않고 그달 수집만 멈춘다(2026-11-03 Vercel 문서 확인).
- **D4. 개인 정보**: 쿠키를 쓰지 않아 동의 배너가 필요 없다. 푸터에 "방문 통계는 쿠키 없이 Vercel Web Analytics로 집계" 한 줄을 넣어 밝힌다.
- **D5.** 사용자 정의 이벤트(목차 클릭 등)는 넣지 않는다. 페이지 조회만 본다.

## 6. 작업 순서

1. 패키지 설치, 레이아웃에 `<Analytics />`, 푸터 안내
2. README에 통계 보는 곳 정리
3. 테스트·lint·빌드
4. 사용자가 Vercel 프로젝트 → Analytics → Enable, 그다음 배포
5. 배포 후 사이트에서 `/_vercel/insights/script.js` 응답 확인
