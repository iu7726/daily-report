**Node.js 개발자 관점:** 모노레포와 다양한 Git 제외 규칙을 사용하는 프로젝트에서 파일 검색 및 컨텍스트 수집의 일관성을 개선하는 수정입니다.

### ⑤ Vercel Labs — `agent-desktop` v1.0.2 공개

릴리스: 10월 31일 06:17 KST · 지난 브리핑 확인 기간에 해당

agent-desktop은 AI 코딩 에이전트가 데스크톱 애플리케이션을 조작하도록 지원하는 오픈소스 CLI입니다.

기존 화면 기반 방식과의 차이

| 방식 | 동작 흐름 |
|---|---|
| 화면 기반 | 스크린샷 분석 → 좌표 판단 → 클릭 |
| agent-desktop | OS 접근성 트리 → 요소 참조 → 실행 |

주요 특징은 Windows·macOS·Linux 지원, JSON 기반 UI 요소 탐색, 요소 참조를 이용한 동작 수행입니다. 이번 `v1.0.2`에서는 npm 실행 시 성능 안내와 macOS 접근 권한 설정 흐름 등이 개선됐습니다.

```bash
npm install -g agent-desktop
agent-desktop version
```

**실무 평가:** 브라우저 밖의 네이티브 데스크톱 앱까지 에이전트 자동화에 포함하고 싶을 때 검토할 만합니다. 다만 접근성 트리에서 제공하지 않는 화면 정보도 있으므로 모든 UI를 정확하게 조작할 수 있는 것은 아닙니다. 민감한 데스크톱 내용이 로그에 포함되지 않도록 주의해야 합니다.

원문: [GitHub 원본](https://github.com/vercel-labs/agent-desktop) · [v1.0.2 릴리스](https://github.com/vercel-labs/agent-desktop/releases/tag/v1.0.2)
