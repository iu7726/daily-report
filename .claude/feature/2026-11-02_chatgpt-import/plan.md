> - **변환 스크립트의 띄어쓰기 손실 수정**: `content_references` 중 `matched_text`가 공백 한 칸인 항목이 있어 메시지 전체의 띄어쓰기가 지워졌다. U+E200 인용 마커가 든 항목만 바꾸도록 고쳤다(출처 링크 285 → 392개로 늘어남).
> - **화면 태그가 더 있었다**: `<Entity>`, `<AsyncImageGroup>`, `<CodeBlock>`, `<Chart>`, `<AsyncImage>`는 변환 목록에 없어 정리 단계(에이전트)에서 처리했다. 검증은 태그 종류와 상관없이 HTML풍 태그를 모두 잡는다.
> - **출처 링크의 `?utm_source=chatgpt.com` 90개 제거**
> - **D7 폴더 구조 변경을 이 작업에 포함** (사용자 결정). 로더는 두 구조를 다 읽고 같은 날짜면 새 구조를 쓴다.
> - 정리 단계 판단: AI는 지원 종료·호환성 변경·보안 수정이 있는 날을 `urgent`(13건 중 5건), S&P500은 원본에 판정이 없어 모두 `notice`, 보안은 KEV·실제 악용·무인증 RCE가 있는 날을 `urgent`(9건 중 7건).
> - **S&P500 행동 권고 문장 삭제 (사용자 요청)**: 정리 단계에서 개인 계획 문장이 "기존 정기 적립 유지, 신규 투자는 서두르지 않음" 같은 일반 권고로 바뀌어 있었다. 이런 문장과 보유·적립·신규 자금 판단 표, `**판단: 기존 전략 유지**` 줄(13줄)을 모두 지웠다. "위험 관리 방침을 점검할 필요" 같은 끝맺음 6문장은 조건·위험 분석만 남겨 "~인지 주의할 필요가 있다"로 바꿨다. 시장 상태 판정(`**종합 판단: 중립 · …**`)은 남겼다. Claude가 쓴 11-02 보고서의 "현금화 계획이 있다면 분할 일정 점검" 문장도 지웠다.
> - **S&P500 작업 규칙 강화**: `scheduler/02-sp500-morning-check.md`에 보유·적립·매수·매도·현금화 같은 행동 권고 문장을 쓰지 않는다는 규칙과 예시를 넣었다.

- 공개 저장소이므로 S&P500에 들어 있던 개인 자금 계획(금액, 일정 등)을 지우거나 일반적인 장기 투자자 관점으로 바꾼다.
- ChatGPT 원본(공유 페이지, 추출 데이터)은 저장소에 넣지 않는다.

- 실행 1회 = 예약 프롬프트(user) 1개 + 보고서(assistant) 1~5개. 보고서 날짜는 프롬프트의 KST 날짜.

## 2. 결정 사항 (확정, 사용자 2026-11-02)

- **D1. 대상**: 각 작업의 예약 실행 결과만. 처음 설정 대화(10-19 AI, 10-23 보안)는 제외. 11-02는 제외.
- **D2. 2단계 처리**: 기계 변환(스크립트: 날짜 분리, 태그 → Markdown, 인용 마커 → 출처 링크) → 보고서별 정리(Sonnet 에이전트 3개: frontmatter, 개인 정보 제거, 제목 줄 통일) → 검증(직접).
- **D3. ChatGPT 작성 표시**: frontmatter `generator: chatgpt`, 본문 맨 위에 옮겨 왔다는 한 줄.
- **D4. 개인 정보**: S&P500의 개인 계획·금액·일정은 모두 지운다. 판단 문장은 "S&P500 ETF 장기 투자자 관점"의 일반 문장으로 바꾼다.
- **D5. 보안 "내 기술 스택 보안 점검"**: 제목만 "기술 스택별 점검"으로 바꾸고 내용은 유지(작업 파일에 이미 공개된 목록).
- **D6. 사실관계는 고치지 않는다**: 당시 ChatGPT가 쓴 내용을 그대로 두고, 형식·개인 정보만 손댄다.
- **D7. 보고서 폴더 구조를 `<작업 ID>/YYYY/MM/DD.md`로 바꾼다 (사용자 2026-11-02, 가져오기와 함께)**: 사이트 속도는 구조와 무관하지만, GitHub 웹은 한 폴더에 1,000개가 넘으면 목록을 다 보여 주지 않는다(작업당 하루 1개 → 약 2년 9개월). 사이트 주소(`/<작업>/<날짜>`)는 그대로다. 사이트는 예전 구조(`<작업 ID>/YYYY-MM-DD.md`)도 읽고, 같은 날짜가 둘 다 있으면 새 구조를 쓴다. 루틴 규칙(`scheduler/CLAUDE.md`)도 새 구조로 바꾼다.
