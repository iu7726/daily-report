### 1. Vercel AI SDK `ai` 6.0.336 — Google MCP 서버 인증 헤더를 텔레메트리에서 가림

11월 23일 07:27 KST(npm 게시)에 6.x 라인의 `ai` 6.0.336이 나왔습니다. 변경 이력상 6.0.334·6.0.335는 npm에 게시되지 않아, 6.0.335에 적힌 수정이 이번 버전으로 처음 배포됐습니다.

`google.mcp_server` 프로바이더 도구는 Interactions MCP 커넥터용으로 `Authorization` 같은 헤더를 받습니다. 그런데 텔레메트리 가림 처리가 OpenAI 도구 ID만 알아봐서, `generateText`·`streamText`의 `ai.prompt.tools` 스팬 속성에 이 헤더 값이 그대로 기록됐습니다. 이제 모든 `google.mcp_server` 헤더 값이 가려지고, 프로바이더로 보내는 요청과 애플리케이션이 쓰는 값은 바뀌지 않습니다.

> 6.x에서 `experimental_telemetry`를 켜고 Google MCP 서버 도구를 쓰는 Node 서비스는 6.0.336 이상으로 올리세요. 이미 기록된 트레이스에는 토큰이 남아 있으니 헤더에 넣었던 토큰을 바꾸고, 트레이스 저장소(Langfuse, Datadog 등)의 보관 데이터와 열람 권한도 확인해야 합니다.

7.x 라인 변경 이력에는 같은 항목이 없습니다. 7.x가 이 문제의 영향을 받는지는 확인 불가입니다.

### `mcp-builder` (anthropics/skills)

외부 API를 MCP 서버로 감싸는 과정을 조사·구현·검토·평가의 4단계로 안내하는 스킬입니다. TypeScript를 권장 언어로 두고, 원격 서버는 상태 없는 Streamable HTTP, 로컬 서버는 stdio를 권합니다. 도구 이름 접두사, Zod 입력 스키마, `outputSchema`·`structuredContent`, `readOnlyHint`·`destructiveHint` 같은 도구 주석, 페이지네이션과 오류 메시지 작성법을 다룹니다.

TypeScript SDK는 새 서버면 v2(`@modelcontextprotocol/server`), 이미 `@modelcontextprotocol/sdk`를 쓰는 프로젝트면 v1을 유지하도록 나눠 안내합니다. 마지막 단계에서는 읽기 전용 질문 10개로 LLM이 서버를 잘 쓰는지 평가하는 XML 파일을 만듭니다.

| 항목 | 값 |
|---|---|
| 설치 수 | 146.3K (확인 2026-11-23 08:48 KST, skills.sh 표시값) |
| 처음 등록 | 2026-01-19(skills.sh 첫 확인일), 신규 아님 |
| 보안 감사 | Gen Agent Trust Hub·Socket Pass, Snyk Warn |

- 원문: [skills.sh](https://skills.sh/anthropics/skills/mcp-builder) · [SKILL.md](https://github.com/anthropics/skills/blob/main/skills/mcp-builder/SKILL.md)
- 설치: `npx skills add https://github.com/anthropics/skills --skill mcp-builder`

동봉된 평가 스크립트 `scripts/evaluation.py`는 Python `anthropic` 패키지로 Claude API를 호출하고, 기본 모델이 `claude-3-7-sonnet-20250219`입니다. 이 모델은 2026년 2월 19일에 종료돼 요청이 실패하므로 `-m` 옵션으로 현재 모델을 지정해야 합니다([모델 지원 종료 목록](https://platform.claude.com/docs/en/about-claude/model-deprecations)).

> NestJS 서비스의 내부 API를 사내 에이전트용 MCP 서버로 내보낼 때 설계 체크리스트로 쓸 만합니다. 다만 평가 단계는 실제 서버에 연결해 도구를 호출하고 API 사용료가 나가므로 운영 데이터가 아닌 스테이징에 붙이고, 쓰기 도구에는 `destructiveHint`를 달았는지 먼저 확인하세요. Snyk 경고 사유는 페이지에 나와 있지 않으니 설치 전에 `scripts/` 폴더를 직접 읽어 보세요.
