## 주요 소식

### 1. Anthropic TypeScript SDK 1.5.0 — 상태·오류 코드별 오류 클래스

11월 5일 05:29 KST에 `@anthropic-ai/sdk` 1.5.0이 npm에 올라왔습니다. HTTP 상태와 API 오류 코드별 오류 클래스가 추가됐고, `APIError`에 `apiMessage`, `errorCode`, `details` 필드가 생겼습니다. 오류 상세(error details) 타입과 새 오류 타입 값, 워크스페이스 목록 조회의 `ids` 필터도 들어갔습니다.

버그 수정으로 `;x`, `.;x`, `..;x` 같은 경로 파라미터를 거부하고, 메모리 도구가 `/memories` 디렉터리 자체를 이름 바꾸거나 지우지 못하게 막았습니다. 스트리밍은 서버 전송 이벤트(SSE)를 청크당 한 번만 디코딩해 성능을 개선했습니다.

> NestJS 예외 필터에서 `error.status === 429` 같은 숫자 비교로 재시도·알림을 가르던 코드는 새 클래스와 `errorCode`로 바꾸면 오류 종류를 더 정확히 구분할 수 있습니다. 사용자 입력을 ID 경로 파라미터로 넘기는 코드는 업그레이드 후 이상한 값이 예외로 바뀌니 입력 검증 단계에서 먼저 걸러 주세요.

- 발표: 2026-11-04(체인지로그 날짜) · [CHANGELOG](https://github.com/anthropics/anthropic-sdk-typescript/blob/main/CHANGELOG.md) · [npm](https://www.npmjs.com/package/@anthropic-ai/sdk)

### 2. openai Node SDK 7.50.0 — 12시간 Responses 캐시, 프로젝트 서비스 등급 설정

`openai` 7.50.0(11/4 11:32 KST)은 Responses API의 12시간 프롬프트 캐시 옵션과 캐시 쓰기 사용량 필드, 프로젝트별 서비스 등급(service tier) 설정 API를 타입으로 추가했습니다. API 기능 자체는 OpenAI API 변경 이력에 10월 20일·21일 항목으로 이미 발표됐고, 이번에 Node SDK가 따라왔습니다.

변경 이력에 따르면 12시간 캐시는 몇 시간 간격으로 들어오는 요청에도 공통 지침·도구·컨텍스트를 캐시해 두고, 12시간 캐시 쓰기는 입력 토큰 단가의 2.5배로 청구됩니다.

> 하루 몇 번만 도는 배치·크론 작업처럼 요청 간격이 긴 서비스는 12시간 캐시로 비용을 줄일 수 있지만, 쓰기 비용이 2.5배라 재사용 횟수가 적으면 오히려 손해입니다. 사용량 로그에 새 캐시 쓰기 필드를 함께 기록해 실제 절감액을 확인한 뒤 켜세요.

- 발표: 2026-11-03(체인지로그 날짜), npm 게시 11/4 · [openai-node CHANGELOG](https://github.com/openai/openai-node/blob/master/CHANGELOG.md) · [OpenAI API 변경 이력](https://developers.openai.com/api/docs/changelog)

### 3. Claude Code 2.1.318 — 로그인 만료 경고, `claude -p` 성공 오보고 수정

어제 보고 때는 변경 이력이 없던 2.1.318(npm 게시 11/4 06:55 KST)의 변경 이력이 올라왔고, `latest` 태그도 2.1.318로 옮겨졌습니다. 저장된 claude.ai 로그인이 끝나는 날짜가 `claude auth status`(`loginExpiresAt`)와 `claude -p` JSON 결과(`credential_expires_at`)에 표시되고, 만료 10일 전부터 `claude -p` 텍스트 출력에 stderr 경고가 한 줄 나옵니다.

수정 사항도 많습니다. API 오류로 응답이 끊겼는데 `claude -p`·Agent SDK 세션이 성공으로 보고하던 문제(모드가 `turn.step`을 훅한 경우), `NODE_EXTRA_CA_CERTS` 파일이 비었거나 PEM이 아니면 모든 연결이 실패하던 문제, `claude mcp add`·`remove`가 잠금 없이 설정을 쓰던 문제가 고쳐졌습니다. `@anthropic-ai/claude-agent-sdk` 0.3.318도 같은 시각에 나왔습니다.

> CI에서 `claude -p` stderr를 오류 판정에 쓰고 있다면 만료 경고 한 줄 때문에 작업이 실패로 잡히지 않는지 확인하고, JSON 출력의 `credential_expires_at`으로 로그인 갱신 알림을 거는 편이 낫습니다. 사내 프록시용 `NODE_EXTRA_CA_CERTS`를 쓰는 환경은 이제 읽을 수 있는 인증서만 쓰고 경고를 남기니 stderr 경고를 한 번 확인해 보세요.

- 발표: 2026-11-04(npm 게시), 변경 이력 게시 시각 확인 불가 · [변경 이력](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

### 4. Gemini CLI 0.67.0 정식판 — `models` 명령, Claude 훅 시간 단위 변환

Gemini CLI 0.67.0이 11월 5일 05:27 KST에 정식 릴리스됐습니다. 모델 목록을 보는 `models` 명령과 `--list-models` 플래그가 추가됐고, 비대화형 모드에서 종료 신호를 처리하며 취소 후에는 도구를 실행하지 않습니다.

설정 이전(migration) 시 Claude 훅의 타임아웃을 초에서 밀리초로 바꾸고, 지원 종료된 설정을 옮길 때 `${VAR}` 자리표시자를 그대로 둡니다. 프로젝트 지출 한도 오류는 재시도하지 않는 할당량 오류로 분류됩니다. 같은 날 0.68.0-preview.0도 나왔는데, 429 대기 시간 표시와 `SubagentStop` 훅 이벤트 매핑이 들어갔습니다.

> Claude Code 훅 설정을 Gemini CLI로 옮겨 쓰는 팀은 업그레이드 후 훅 타임아웃 값이 의도대로 바뀌었는지 설정 파일을 확인하세요. CI에서 Gemini CLI를 돌리다 지출 한도에 걸리면 이제 재시도 없이 바로 실패합니다.

- 발표: 2026-11-04(UTC) · [Gemini CLI 릴리스](https://github.com/google-gemini/gemini-cli/releases)

### 5. OpenAI GPT-Image-2.6 Sunburst·Flare 공개
