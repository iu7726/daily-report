### `git-guardrails-claude-code` (mattpocock/skills)

Claude Code에 PreToolUse 훅을 설치해 Bash 도구로 실행하려는 git 명령을 검사하고, 위험한 명령이면 실행 전에 막는 스킬입니다. 기본 차단 목록은 `git push`(모든 형태), `git reset --hard`, `git clean -f`·`-fd`, `git branch -D`, `git checkout .`·`git restore .`입니다.

설치 범위를 프로젝트(`.claude/settings.json`)와 전체(`~/.claude/settings.json`) 중에서 묻고, `block-dangerous-git.sh`를 `.claude/hooks/`에 복사한 뒤 설정에 훅을 합칩니다. 차단하면 종료 코드 2와 함께 BLOCKED 메시지를 돌려줍니다.

저장소의 동결 안내에는 이미 보고된 한계가 적혀 있습니다. 스크립트가 명령 문자열을 단순 패턴으로 비교해 `git -C <dir> push`처럼 전역 옵션을 넣으면 통과하고(#301), `jq`가 없으면 명령을 읽지 못해 아무것도 막지 않습니다(#898). 실제 스크립트도 `jq` 결과가 비면 종료 코드 0으로 끝납니다.

> NestJS 저장소에서 에이전트에게 리팩터링을 맡길 때 실수로 인한 `push`나 `reset --hard`를 막는 1차 장치로는 쓸 만합니다. 하지만 우회가 쉬워 보안 경계가 아니므로, 원격 저장소는 브랜치 보호 규칙으로 지키고 Claude Code의 `permissions.deny` 규칙과 함께 쓰세요. 설치 전에 `jq`가 있는지, 팀원이 쓰는 `git` 별칭이 패턴에 걸리는지 확인해야 합니다.
