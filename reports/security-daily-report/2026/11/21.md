ssosync는 Google Workspace의 사용자·그룹을 IAM Identity Center로 동기화하는 AWS 오픈소스 도구입니다. 불변 식별자로 짝을 찾지 못하면 이메일 주소나 그룹 이름으로 기존 사용자·그룹을 찾아 그 자리에서 갱신했습니다. 그래서 퇴사자 이메일을 새 직원에게 다시 주거나 그룹 이름을 재사용하면, 새 계정이 이전 사용자의 그룹 멤버십과 권한 세트를 그대로 물려받습니다.

## 6. 데이터베이스

### ② [P2] Valkey — 클라이언트 축출이 실행 중인 명령의 클라이언트를 해제

클라이언트 축출(client eviction)이 아직 명령을 실행하고 있는 클라이언트를 메모리에서 해제해 해제 후 사용(use-after-free)이 생깁니다. 로그인한 사용자가 다른 클라이언트가 `BLPOP`·`XREAD BLOCK` 등으로 기다리는 키에 쓰기만 하면 서버를 확실하게 죽일 수 있습니다. 기다리는 클라이언트가 공격자 것일 필요는 없습니다.

`maxmemory-clients`를 0이 아닌 값으로 켠 서버만 해당합니다. 기본값(0)은 해당하지 않고, Redis 본체에 대한 권고는 아닙니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| 9.1.3·9.0.7·8.1.11·8.0.12·7.2.15 이하, 9.2.0-rc2 이하 | 9.2.0, 9.1.4, 9.0.8, 8.1.12, 8.0.13, 7.2.16 | CVE-2026-130822, GHSA-3885-pq5f-788j | 7.5 (CVSS 3.1) | 미등재 · 확인 불가 |

> 큐·작업 대기열에 블로킹 명령을 쓰면서 클라이언트 축출을 켠 Valkey라면, 일반 사용자 계정 하나로 서버가 내려갈 수 있습니다.

- `CONFIG GET maxmemory-clients`가 0이 아니면 위 수정 버전으로 올립니다. ElastiCache·MemoryDB 같은 관리형 서비스는 공급자 공지를 따릅니다.
- 바로 못 올리면 `maxmemory-clients`를 0으로 두거나, ACL로 블로킹 키 쓰기와 블로킹 명령 사용을 제한합니다.
- 원문: [GHSA-3885-pq5f-788j](https://github.com/valkey-io/valkey/security/advisories/GHSA-3885-pq5f-788j) (2026-11-19 게시, 시각 확인 불가. 어제 보고에서 놓쳐 오늘 다룹니다)

참고

## 7. 공급망·CI/CD·인프라

### ① [P1] Ruby2Shell — GitLab 수정판 배포, GitHub Enterprise Server는 수정판 없음(발견자 기준)

Ruby 정규식·문자열 메모리 취약점(Ruby2Shell)으로 기본 설정 Rails에서 인증 없이 코드를 실행할 수 있다는 건입니다. 어제 아침에는 GitLab 수정판이 없었지만, GitLab이 11월 20일 19.6.1 / 19.5.8 / 19.4.10을 냈습니다(어제 18:15 후속 확인).

발견자 Veria Labs는 2026-11-21 08:00 KST 갱신에서 GitHub Enterprise Server 3.22.5 이하를 "Vulnerable, 수정판 없음"으로 분류했습니다. GHES의 최신 패치 3.22.5(11월 17일) 릴리스 노트에는 이 건이 없고, GitHub 공식 공지도 아직 없습니다. Chatwoot, Mastodon, OpenProject, Discourse는 수정판이 나왔습니다.

AWS는 WAF 관리형 규칙 그룹 Known Bad Inputs 1.29에 Ruby2Shell 탐지 규칙 3개를 넣었습니다. 정상 요청도 걸릴 수 있어 Count 모드로 배포됐고, 막으려면 직접 Block으로 바꿔야 합니다. Amazon Linux 2023 패키지와 Elastic Beanstalk Ruby 플랫폼 4.15.4가 나왔고, Lambda 관리형 Ruby 런타임은 배포 중입니다.

## 10. 미확인 보도·루머

- GitHub Enterprise Server가 Ruby2Shell에 취약하다는 판단은 발견자 Veria Labs의 분류에만 있습니다. GitHub 공식 공지와 GHES 릴리스 노트로는 아직 확인되지 않았습니다.
- Hacker News 제목의 OpenSSL CVE-2026-121481 "CVSS 9.8"은 OpenSSL(Low)·NVD(5.9) 어느 쪽과도 맞지 않습니다.

Hacker News 상위 글(24시간, 100점 이상 35개) 중 보안 관련 글은 OpenSSL `EVP_EncodeBlock()`(⑨에서 다룸)과 Visa·Mastercard·JPMorgan 고객 정보 유출 보도입니다. 유출 보도는 점검 대상에 닿지 않습니다.
