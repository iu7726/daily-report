## 7. 공급망·CI/CD·인프라

### ① [P1] Ruby2Shell — GHES 수정판 여전히 없음, 발견자는 PoC 공개를 미룰 수 있다고 밝힘

Ruby 정규식·문자열 메모리 취약점(Ruby2Shell)으로 기본 설정 Rails에서 인증 없이 코드를 실행할 수 있다는 건입니다. 발견자 Veria Labs는 2026-11-21 12:52 KST 갱신에서도 GitHub Enterprise Server 3.22.5 이하를 "Vulnerable, 수정판 없음"으로 두었습니다. GHES 3.22 릴리스 노트의 최신판도 여전히 3.22.5(11월 17일)이고, 이 건은 들어 있지 않습니다.

이번 갱신에서 Veria Labs는 PoC 공개일을 11월 25일로 유지하되, 그때까지 주요 벤더가 수정판을 내지 않으면 공개를 늦추겠다고 덧붙였습니다. 실제 악용 보고는 아직 없습니다. GitHub는 11월 20일 GHES 3.23 릴리스 후보를 냈지만 Ruby2Shell 언급은 없습니다.

|---|---|---|---|---|
| Ruby 3.3.14 / 3.4.13 / 4.0.10 미만 · GitLab 19.6.0 이하 · GHES 3.22.5 이하(Veria Labs 기준) | Ruby 4.0.10, 3.4.13, 3.3.14 · GitLab 19.6.1, 19.5.8, 19.4.10 · GHES 확인 불가(미출시) | CVE-2026-132825 외 6건 | MITRE 7.4 (Ruby 보안팀 평가 Critical) | 미등재 · 확인 불가 |

> PoC 공개가 늦춰질 수는 있지만 날짜가 바뀐 것은 아닙니다. GHES를 인터넷에 열어 두었다면 11월 25일 전에 접근 경로를 줄여 두어야 합니다.

- GitHub Enterprise Server를 운영한다면 VPN·IP 허용 목록 뒤로 옮기고, Ruby 수정이 들어간 패치(3.22.6 등)가 나오면 바로 올립니다. 후속 확인 등록됨(어제).
- self-managed GitLab과 Ruby 앱 조치는 어제 보고와 같습니다. GitLab 19.6.1 / 19.5.8 / 19.4.10, Ruby 4.0.10 / 3.4.13 / 3.3.14 이상인지 확인합니다.
- 원문: [Veria Labs Ruby2Shell](https://verialabs.com/ruby2shell/) (2026-11-21 12:52 KST 갱신) · [GHES 3.22 릴리스 노트](https://docs.github.com/en/enterprise-server@3.22/admin/release-notes) · [GitHub Changelog](https://github.blog/changelog/) (GHES 3.23 RC, 2026-11-20)

GitHub Actions 생태계(OSV)는 조사 기간에 새 권고가 없습니다. Docker 보안 공지의 최신 글은 Docker Desktop 4.97.0, OpenSSH는 11월 5일 10.6p2, OpenSSL은 11월 17일 Low 항목, nginx는 11월 18일 1.30.7 / 1.31.9 이후 새 소식이 없습니다. 이상 없음으로 확인한 대상: npm 생태계 공급망(④ 외 신규 사고 없음), GitHub Actions, GitLab, Docker
