### ③ GitHub — Agentic Workflows 정식 출시

발표 10월 28일 · 중요도 매우 높음 · CI/CD 자동화

GitHub Agentic Workflows가 정식 제공(GA) 단계로 전환됐습니다.

Markdown 파일에 자연어로 작업을 정의하면 이를 GitHub Actions 워크플로로 컴파일해 실행합니다.

예를 들어 Issue 분류, CI 실패 분석, 문서 업데이트, 테스트 작성 같은 업무를 자동화할 수 있습니다.

- 기존 GitHub Actions Runner와 조직 정책 재사용
- 기본 읽기 전용 권한, 샌드박스 및 방화벽 보호
- GitHub Copilot 또는 자체 코딩 에이전트 사용 가능
- ARC, Docker-in-Docker 지원
- `gh aw forecast`로 AI 사용 비용 예측

**제공 범위:** GitHub Free, Team, Enterprise. 단, 기본 Copilot CLI 엔진을 사용하려면 Copilot 라이선스가 필요합니다.

같은 날 **Shared Copilot Automations**도 발표됐습니다. 개인이 아닌 저장소가 자동화의 소유자가 되어 팀원이 공동 관리할 수 있으며, 비용은 저장소 소유자에게 청구됩니다.

**실무 적용:** NestJS 프로젝트의 CI 실패 분석이나 PR 검증 결과 보고를 자동화하고, 팀원 퇴사 후에도 유지되는 형태로 구성할 수 있습니다.

원문: [Agentic Workflows GA](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available/) · [Shared Automations](https://github.blog/changelog/2026-10-28-build-shared-workflows-for-your-team-with-copilot-automations/)
