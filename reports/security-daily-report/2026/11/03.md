## 4. AI·개발 도구

### ⑤ [P1] Claude Code VS Code 확장 — Cursor 마켓플레이스에 SSH 백도어 변조판 배포

10월 29일 Cursor의 확장 마켓플레이스에 `anthropic.claude-code` 2.1.312·2.1.313 변조판이 올라왔습니다. 정상 코드 앞에 약 7KB 로더를 붙여, 확장이 로드되면 사용자 조작 없이 `svc-telemetry` SSH 키를 `authorized_keys`에 넣고 원격 로그인을 켠 뒤 `134.209.82.225`로 역방향 SSH 터널을 엽니다. 재부팅 후에도 살아남도록 LaunchAgent(`com.apple.sysmond`), 예약 작업(`SysMon`), cron `@reboot`을 남깁니다.

Cursor는 20:35 UTC에 배포를 막고 마켓플레이스를 내렸다가 다시 구축했고, 공격자 서버는 10월 30일 내려갔습니다. 공격자가 어떻게 마켓플레이스에 접근했는지는 밝히지 않았습니다. Anthropic은 공식 배포 채널(VS Code Marketplace 등)은 영향이 없다고 밝혔고, Open VSX의 2.1.312는 정상본으로 확인됐습니다(StepSecurity 분석).

Cursor에서 그 시간대(10월 29일 09:27~20:35 UTC)에 이 확장을 받거나 자동 업데이트한 macOS·Windows PC만 해당합니다. VS Code에서 Microsoft 마켓플레이스로 받은 경우와 Claude Code CLI(npm)는 해당하지 않습니다.

> Cursor를 쓴다면 지금 `grep svc-telemetry ~/.ssh/authorized_keys`로 확인하고, 키가 나오면 그 PC를 침해된 것으로 보고 다른 기기에서 그 PC가 쓰던 토큰·키를 모두 교체해야 합니다.

| 영향 버전 | 수정 버전 | 식별번호 | CVSS | KEV·실제 악용 |
|---|---|---|---|---|
| Cursor 마켓플레이스의 `anthropic.claude-code` 2.1.312, 2.1.313 (darwin-arm64, win32-x64) | 2.1.314 이후(Anthropic은 혼동을 막으려 2.1.313을 건너뜀) | CVE 없음 | 해당 없음 | 실제 배포 확인(Cursor 공지) |

- 키가 없으면: 그 확장을 2.1.314 이후로 바꾸고 끝입니다. Cursor는 관리자 권한이 없으면 키 추가와 SSH 켜기는 보통 실패한다고 밝혔습니다.
- 키가 있으면: Cursor 공지의 정리 스크립트(`remediate-macos.sh`, `remediate-windows.ps1`)로 키·지속 실행 항목·터널 프로세스를 지우고, 재설치를 검토합니다. 확장 삭제만으로는 부족합니다.
- 원문: [Cursor 보안 공지](https://cursor.com/blog/claude-code-extension-security-notice) (2026-10-29, 갱신 2026-10-30 11:30 PT) · [StepSecurity 분석](https://www.stepsecurity.io/blog/claude-code-extension-trojanized) (2026-10-30)
