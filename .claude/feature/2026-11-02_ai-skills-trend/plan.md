## 2. 결정 (사용자 2026-11-02)

- **D1. "주목할 Agent Skills" 1~3개**: 직전 24시간 제한 없이 skills.sh 트렌딩·설치 수 기준. 이름·링크, 설치 수와 확인 시각, 처음 등록 시기(오래되면 "신규 아님"), 하는 일, 설치 명령(원문 그대로), 백엔드 실무 평가와 주의점. 이전 보고서에서 다룬 스킬은 크게 바뀐 경우만 다시 다룬다. 조사만 하고 설치하지 않는다.
- **D2. 새 소식이 없는 날에도 스킬 항목은 쓴다.**
- **D3. 우선 참조 출처 표**: ChatGPT가 정했던 출처(OpenAI 뉴스·API 변경 이력, DeepMind 블로그, Gemini API 변경 이력, Anthropic 뉴스, Claude Code 변경 이력, skills.sh, Anthropic Skills, Vercel Agent Skills, 업계 매체)에 Claude 루틴이 실제로 쓰던 출처(Codex·Gemini CLI 릴리스, Claude Platform 릴리스 노트, MCP 블로그·TypeScript SDK 릴리스)를 더한다. 업계 매체는 보조이며 1차 자료로 확인되지 않으면 미확인 보도로 분리한다.
