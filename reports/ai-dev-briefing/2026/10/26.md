오늘 확인한 skills.sh 24시간 인기 목록에서 약 **2,200건의 설치**가 표시됐습니다.

2026년 7월부터 확인되는 기존 Skill로, 오늘 새로 출시된 것은 아닙니다.

**무슨 기능인가?**

TypeScript 프로젝트의 패키지 내부 구현을 외부 모듈이 직접 참조하지 못하도록 의존성 규칙을 적용합니다.

핵심 개념은 Deep Module입니다.

```text
src/packages/reservation/
├── index.ts           // 외부에 공개
├── lib/
│   ├── service.ts     // 내부 구현
│   ├── repository.ts
│   └── validator.ts
└── tests/
```

외부 모듈은 다음과 같이 패키지의 공개 인터페이스를 사용합니다.

```typescript
// 허용
import { createReservation } from "@/packages/reservation";

// 금지
import { createReservation } from "@/packages/reservation/lib/service";
```

Skill은 `dependency-cruiser`를 설치하고 내부 구현에 직접 접근하는 의존성을 검사하는 규칙을 구성합니다.

**NestJS 개발자 관점**

모듈 간 결합도를 통제하는 데 활용할 수 있습니다.

특히 규모가 커진 NestJS 프로젝트에서 Service와 Repository를 다른 모듈이 직접 참조하는 상황을 줄이는 데 도움이 됩니다.

다만 NestJS의 기존 모듈 공개 방식, DI 구조와 충돌하지 않도록 검토해야 합니다.

설치:

```bash

```

인기 목록의 설치 수는 관심도를 나타내며 설계의 우수성을 입증하지는 않습니다. 원본 지침을 검토하고 별도 브랜치에서 적용하는 것이 좋습니다.
