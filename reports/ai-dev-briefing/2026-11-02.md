- **개발자 의미**: 클라이언트에서 Firebase AI Logic으로 Gemini를 직접 호출하는 앱은 App Check 토큰이 없으면 요청이 거부될 수 있다.

### 2. OpenAI API — reusable prompts·Evals·Agent Builder 종료 (발표 2026-06-03, 종료 2026-11-30)
- **핵심 변경**: `v1/prompts` API와 prompt 객체, Evals 플랫폼(대시보드·API), Agent Builder가 11/30 종료된다. 대체: 프롬프트는 애플리케이션 코드로 이동, Evals는 Promptfoo, Agent Builder는 Agents SDK 또는 ChatGPT Workspace Agents.
- **원문**: https://developers.openai.com/api/docs/deprecations
- **실무 포인트**: Node.js 코드에서 `prompt: { id: ... }` 형태로 저장된 프롬프트를 참조하는 Responses API 호출을 검색해 템플릿을 코드(또는 자체 설정 저장소)로 옮긴다. 같은 페이지에 12/1 이미지 모델, 12/11 `gpt-5`·`o3` 계열 종료도 있다(대체: `gpt-5.6-sol` 등).
